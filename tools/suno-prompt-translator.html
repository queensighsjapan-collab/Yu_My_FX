歌詞タグ翻訳機 for Suno AI

歌詞本文はそのまま、[ ] で囲んだ指示タグだけをSunoが理解しやすい英語に変換します。歌詞は日本語のまま歌わせてOK、タグだけ英語にするのがコツです。

はじめての方へ:APIキーの取得方法(3分でできます)

「APIキー」は、このページがAI(Claude)に翻訳をお願いするための、あなた専用の「合言葉」です。無料で発行できます。

  1. console.anthropic.com を開いて、メールアドレスなどで登録します(すでにClaudeを使っている方は同じアカウントでログインできます)
  2. ログインしたら、左側のメニューから API Keys(APIキー)という項目を探してクリックします
  3. Create Key(キーを作成)のようなボタンを押します。名前は何でも構いません(例: 「suno-tool」)
  4. 表示された文字列(sk-ant-...で始まる長い文字列)をコピーします。この画面を閉じると二度と表示されないので、必ずこの時にコピーしてください
  5. コピーした文字列を、下の「Anthropic APIキー」欄に貼り付ければ準備完了です

お金はかかる? 新規登録時に少額の無料クレジットが付くことが多いですが、それを使い切ると利用量に応じた少額の課金が発生します。金額の詳細はconsole.anthropic.com内のBilling(お支払い)ページで確認できます。

安全性について: このキーはあなたのブラウザの中だけで使われ、翻訳のたびにAnthropicへ直接送られます。ページを閉じたり再読み込みすると消えるので、次回また貼り付け直す必要があります。他人に見せたり、他のサイトに貼り付けたりしないでください。

このブラウザのタブを閉じると消えます。どこにも保存・送信(Anthropic以外へ)されません。

Sunoはアーティスト名を書くと弾かれたり無視されたりします。ここに入れると、名前を使わずに「年代・楽器編成・ボーカルの質感・音作り」だけでその雰囲気を表す英語タグを自動生成し、下の変換結果の先頭に追加します。
