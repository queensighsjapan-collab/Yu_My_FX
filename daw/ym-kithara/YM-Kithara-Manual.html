はじめに

YM-Kithara（ワイエム・キターラ）は、曲の編集からミュージックビデオの仕上げまでを1本でまかなう、Windows用デスクトップDAW「AV Workstation」です。Suno AIなどで作った曲やステムをタイムラインで編集し、VST3エフェクトやVST楽器を足し、動画と歌詞テロップを合わせて、最後は1本のmp4に書き出す――という使い方を想定しています。

動作環境とファイルの置き場所

  • 対応OS：Windows（64bit）
  • プログラムは2つ1組です。YM-Kithara.exe と KitharaVstScanner.exe は、必ず同じフォルダに置いてください。スキャナはプラグイン探し専用の小さいプログラムで、普段は触らなくて大丈夫です。
  • 同じフォルダには、動画再生に使うFFmpegのDLL（avformat-*.dll、avcodec-*.dll、avutil-*.dll、swscale-*.dll、swresample-*.dll）も並んでいます。これらのDLLが無いとアプリが起動しません。消したり別のフォルダへ移したりしないでください。

メモ：KitharaVstScanner.exe が無い場合でもアプリ本体は起動しますが、「Scan for Plugins...」（プラグイン探し）が使えなくなります。

初回起動：音の出る装置を選ぶ

  1. YM-Kithara.exe を起動します。
  2. 画面上部の Audio Settings... を押すと、オーディオ装置の選択画面が開きます。
  3. 使いたい出力装置（スピーカー／ヘッドホン／オーディオインターフェース）を選びます。ドライバの種類は、通常は WASAPI のままで大丈夫です。ASIO対応の環境でビルドした場合は ASIO も選べます（ASIOのほうが遅延が小さくなります）。
  4. 画面は Space キーでも再生／一時停止できます（文字入力中はそちらが優先されます）。

プロジェクトの新規作成・開く・保存

  • New：新しいプロジェクトを作ります。
  • Open Project...：保存済みプロジェクトのフォルダを選びます。
  • Save Project...：保存先フォルダを選ぶと、そのフォルダに project.xml と audio/ フォルダが作られます。

オーディオ素材は、保存時にプロジェクトフォルダ内の audio/ へコピーされます。一方、動画ファイルはコピーされず、元の場所（絶対パス）への参照だけが記録されます。元の動画ファイルを移動・削除すると、その動画クリップは開けなくなります（詳しくは「動画（静止画）編」と「困ったとき」）。

メモ：素材ファイルが見つからない状態でプロジェクトを開くと、警告が出て、そのクリップだけを落として読み込みます（プロジェクト全体が開けなくなることはありません）。

音声編

オーディオファイルを取り込む

  1. Import File... を押してファイルを選ぶか、ファイルをウィンドウのどこへでもドラッグ＆ドロップします。
  2. ファイル1つにつき新しいオーディオトラックが1本でき、先頭にクリップが置かれます（ステムを並べる作業向けの仕様です）。

読み込める形式は、WAV / AIFF / FLAC / Ogg / MP3 などです。取り込んだ音声はデバイスのサンプルレートに合わせて内部保持されます。

クリップの編集

クリップの編集はすべて非破壊です。元の音声データは一切変更されません。

操作やり方
選択クリップをクリック
移動クリップをドラッグ。上下にドラッグすると別のオーディオトラックへも移せます
トリム（伸ばし縮み）クリップの左右の端（約6pxの範囲）をドラッグ。素材の範囲内まで伸縮できます
分割再生ヘッドをクリップの中に入れて、下部バーの Split at Playhead を押す
削除クリップを選んで Delete キー、または Delete Clip
フェードと音量クリップを選ぶと下部バー（インスペクター）に Fade In / Fade Out（各0〜5秒）とクリップの Gain が出ます。フェードを付けると音の入り・終わりがなめらかになります

トラックの操作

  • 名前：トラック名をダブルクリックで編集できます。
  • M（ミュート）：そのトラックを無音にします。S（ソロ）：ソロが1つでもONのときは、ソロのトラックだけが鳴ります。
  • 音量：ヘッダーの小さいスライダーでトラック音量を調整します。
  • 削除：ヘッダーの × でトラックごと削除します。
  • メーター：ヘッダー右端にステレオのピークメーターがあります。音が割れる大きさ（フルスケール）に達すると赤いランプ（クリップLED）が点いたままになります。音量を下げて調整し、ランプはクリックで消えます。トランスポート行の MASTER メーターは最終出力用で、こちらにもクリップLEDがあります。
  • 表示の拡大：右下の Zoom スライダーで横方向、V Zoom スライダーでトラックの高さ（40〜160px）が変わります。タイムライン上で Ctrl＋マウスホイールでも縦ズームできます。再生中は再生ヘッドが画面端まで行くと自動でスクロールして追いかけます。

各トラックにはVST3エフェクトを挿せます。挿し方は「VST編」を見てください。挿したエフェクト名は、トラック名の下にも「FX: 名前 > 名前」の形で小さく表示されます（バイパス中は名前に (off) が付きます。トラックの高さが小さいときは表示されません）。

WAVに書き出す（ミックスダウン）

  1. 上部の Export WAV... を押します。
  2. 保存先とファイル名を選びます（初期名は mixdown.wav）。
  3. しばらく待つと書き出しが終わり、ステータス行に「Exported: ...」と出ます。
  • 書き出し範囲はセッション全体＋終わりに2秒の余韻です。
  • 形式は16bit PCM WAV（エンジンのサンプルレート）。楽器・FX・プラグイン遅延補償（PDC）・マスター音量まで含めて、再生時と同じ音で書き出されます。
  • 書き出し中はプログレス表示が出て、再生は自動で止まります。

動画（静止画）編

動画トラックと読み込み

動画トラックは1本だけです。

  1. Add Video... を押して動画ファイルを選ぶか、動画ファイルをウィンドウへドラッグ＆ドロップします。対応形式は mp4 / mov / mkv / m4v です。
  2. 動画トラックが（無ければ）作られ、クリップが末尾へ追加されます。もう1本読み込むと、後ろにつながります。
  3. レーンには、元動画の1秒ごとのサムネイル（フィルムストリップ）が並びます。サムネイルは裏側で順次作られるので、最初は単色で表示され、少し待つと絵に置き換わります。

注意：動画ファイルはプロジェクトフォルダへコピーされません。プロジェクトには動画ファイルの場所（絶対パス）だけが記録されます。元の動画ファイルを移動・名前変更・削除すると、そのクリップは開けなくなります（警告が出て、そのクリップだけ落ちます）。プロジェクトを別のPCへ持っていくときは、この点に注意してください。

なお、動画トラック自体は音を出しません。動画ファイル自身の音を使いたいときは、後述の「動画の音声を取り込む（Extract Audio）」を使ってください。動画トラックにFX・楽器・音量・メーターはありません。

プレビューで映像を見る

  1. トランスポート行の Video ボタンを押すと、プレビューウィンドウ（別ウィンドウ）が開きます。もう一度押すか、ウィンドウを閉じると消えます。
  2. 再生・停止にフレーム単位で追従します。止めたままルーラーをクリック／ドラッグ（スクラブ）しても、その位置の絵に切り替わります。
  3. 絵はアスペクト比を保って表示され（レターボックス）、クリップの無い位置では黒画面になります。

クリップの編集

基本操作はオーディオクリップと同じです：ドラッグで移動、両端のドラッグでトリム（元動画の範囲内まで）、Split at Playhead で分割、Delete で削除。

重なり＝クロスディゾルブ

動画トラックだけは、クリップ同士を重ねて置けます。重なった区間では、前の映像から次の映像へ自動でクロスディゾルブします（後から始まるクリップが上になり、重なりの進み具合で徐々に切り替わります）。3本以上の重なりでも同じ規則で合成されます。プレビューとmp4書き出しで、同じ見え方になります。

フェード（黒から／黒へ）

  • クリップの左上の角を右へドラッグするとフェードイン、右上の角を左へドラッグするとフェードアウトが付きます。フェードの範囲には三角の陰影と対角線が描かれます。
  • 下に映像が無いところでは、黒からのフェードイン／黒へのフェードアウトになります。下に映像があるところでは、そのクリップ自身の不透明度として効きます。
  • フェード範囲は0〜クリップ長で、トリムや移動をしても長さに合わせて自動で締められます。クリップを分割すると、左の片はフェードインを、右の片はフェードアウトを引き継ぎます（新しい切り口のフェードは0です）。

静止画（jpg / png / bmp）を置く

  • 読み込み方は動画と同じです（Add Video... かドラッグ＆ドロップ）。タイトルカードやジャケット絵に使えます。
  • 置いた直後は5秒のクリップになります。絵が変わらないので、右端を引っ張れば何秒にでも伸ばせます（左端は開始位置の移動だけです）。
  • 動画との重なり（ディゾルブ）、黒フェード、テロップの合成、mp4書き出しも、そのまま静止画に効きます。分割すると両方とも静止画クリップになります。

動画の音声を取り込む（Extract Audio）

動画ファイルに入っている音（スマホ動画の環境音など）を、普通のオーディオトラックとして取り込めます。

  1. 上部の Extract Audio ボタンを押します（少し待ちます）。
  2. 元ファイルごとに「（動画の名前） Audio」というトラックができ、そのファイルの動画クリップと開始位置・長さがぴったり同じ音声クリップが並びます。
  3. あとは通常のオーディオトラックと同じです。ミュートすればその音だけ消せますし、フェードや書き出しの対象にもなります。
  • 音声は動画ファイルの隣に「（動画の名前）_audio.wav」というファイルで保存されます。プロジェクト保存時は、他の取り込み素材と同じくプロジェクト内にもコピーされます。
  • もう一度押してもトラックは増えません（「取り込み済み」としてスキップされ、その旨が表示されます）。
  • 音声の入っていない動画は、ファイル名を表示してスキップされます。静止画クリップは対象外として黙ってスキップされます。

メモ：モノラル素材の動画から取り込んだ音声は、ステレオ化の都合で約3dB小さくなります。気になる場合は、そのトラックの音量やクリップのGainで調整してください。

タイムコード表示

トランスポート行にタイムコード（HH:MM:SS:FF の形）が大きく表示されます。

  • 最初の動画を読み込んだとき、その動画のフレームレートがセッションのタイムコードレートとして自動で採用されます（自分で固定したことがある場合はそちらが優先されます）。
  • タイムコードの右隣のプルダウン（23.976 / 24 / 25 / 29.97 DF / 30 / 50 / 59.94 DF / 60）で選ぶと、そのレートに固定されます。動画が無く未固定の場合は30 fpsです。
  • 29.97と59.94はドロップフレームで、区切りが ; になります（例：01:00:00;00）。ドロップフレームでは、実時間ちょうど60.0秒が 00:00:59;28 と表示されますが、これはドロップフレームの正しい数え方です（故障ではありません）。
  • 動画クリップの長さもセッションの長さに含まれます。動画だけのプロジェクトでも再生できますし、音声より長い動画が書き出しで途中で切れることもありません。

mp4に書き出す

  1. 上部の Export MP4... を押します（動画トラックが無い場合は、その旨の案内が出て止まります）。
  2. 設定の小窓で、サイズと画質を選びます（最初はそのままで大丈夫です）。
    • Picture size：Original（先頭クリップの大きさ）／ 1920×1080 ／ 1280×720 ／ 1080×1920（縦9:16、Shorts／TikTok用）
    • Quality：High（CRF 18）／ Standard（CRF 23）／ Light（CRF 28）。Highはきれいですがファイルが大きく、Lightは軽い代わりに少し粗くなります
  3. 保存先とファイル名を決めると書き出しが始まり、進み具合のバーが出ます。途中でキャンセルもできます（その場合、書きかけのファイルは残りません）。
  • 書き出しの長さはWAV書き出しとまったく同じ（セッションの長さ＋2秒の余韻）です。映像の無い区間は黒画面で、音だけが流れます。テロップもそのまま焼き込まれます。
  • 音声はAAC 192 kbps（48 kHz）で、映像はH.264です。普通の動画プレイヤーやスマホでそのまま再生できます。
  • 元動画はアスペクト比を保ったまま画面に収められ、余りは黒帯で埋まります（引き伸ばし・切り抜きはしません）。縦動画サイズに横動画を入れると上下に黒帯が付きます。
  • フレームレートはセッションのタイムコードレートです。元動画のfpsと違う場合は、フレームの複製／間引きが起きます（音に同期するのが正で、映像は一番近い瞬間の絵が選ばれます）。
  • 書き出し前に全クリップの元ファイルをチェックし、見つからないものがあればファイル名を表示して中止します。

MIDI編

MIDIトラックと楽器

  1. 上部の Add MIDI Track を押すと、MIDIトラックが増えます。MIDIトラックはオーディオクリップの代わりに、楽器スロット（1つ）とMIDIクリップを持ちます。
  2. MIDIクリップをクリックして選ぶと、下部バーの左側に「Inst: (none)」と出るので、Add Instrument... を押して楽器（シンセ）を選びます（一覧に出るのは楽器だけです。一覧が空の場合は、先に「VST編」のスキャンを1回行ってください）。
  3. 楽器の画面は Open Inst で開けます。外すときは Remove Inst です。
  4. MIDIトラックにも Add FX... でエフェクトを挿せます（楽器の後段にかかります）。

トラックヘッダーの要約行は、MIDIトラックでは「Inst: 名前 | FX: ...」の形になります。楽器が入っていない／見つからないトラックは無音です（見つからない場合は名前と設定が保持されたまま残ります）。

MIDIクリップを作る

  • MIDIトラックのレーンの何もない所をダブルクリックすると、その小節の頭に1小節長（4拍）のMIDIクリップができます。
  • クリップはクリックで選択、横ドラッグで移動、Delete で削除できます（別のトラックへの移動はできません）。
  • クリップの位置と長さは秒で保持され、セッションの長さにも数えられます。

ピアノロールで音符を書く

MIDIクリップをダブルクリックすると、ピアノロールが別ウィンドウで開きます。左端が鍵盤（Cの行に音名表示）、横軸はクリップ内の拍です（4拍ごとに小節線）。

操作やり方
音符を置く空いているマスをクリック。置く位置は0.25拍スナップ、長さは「最後に使った長さ」（初期値0.5拍）、ベロシティは100固定です
移動音符をドラッグ（上下＝音程、左右＝タイミング。スナップあり）
長さ変更音符の右端（約4px）をドラッグ（最小0.1拍）
削除音符を選んで Delete / Backspace、または右クリック

変更はその場で反映されます。現行版のピアノロールでできないこと：ベロシティの編集、複数選択、ピアノロール内の再生ヘッド表示。

大事：先にテンポ（BPM）を合わせてください。音符はクリップの中で「拍」で覚えられています。音符を置いたあとでテンポを変えると、音符どうしの間隔が伸び縮みしてしまいます（クリップ自体の位置と長さは変わりません）。曲のBPMは、トランスポート行の Tempo 欄で先に合わせてから、音符を置いてください。録音のときも同じ約束です。

MIDIクリップを伸ばす・縮める（トリム）

  • クリップの左右の端（約6px）をドラッグすると、他のクリップと同じようにトリム／延長できます（最小長は0.25拍ぶんです）。
  • 右端を伸ばすと空の拍が増え、ピアノロールもその分広がります。1小節のクリップを伸ばして続きを書き足せます。
  • 縮めると、範囲の外に出た音符は鳴らなくなり、ピアノロールにも出なくなります。ただし音符のデータは消えません。再び伸ばせば元どおり現れます。トリムしたクリップをピアノロールで編集しても、隠れた音符が消えることはありません。
  • 左端を引っ張ると、残った音符のタイミングはずらさずに、頭の部分だけを切り取れます（開始位置より前に始まる音符は鳴りません）。

MIDIファイル（.mid）を読み込む

  1. Import File... で .mid ファイルを選ぶか、ウィンドウへドラッグ＆ドロップします（音声ファイルと混ぜて選んでも大丈夫です）。
  2. ファイル内の音符のあるトラックごとに、MIDIトラックが1本ずつできます。音符は各トラックの先頭のクリップにまとめて入ります。音符の無いトラック（コンダクタートラック等）は読み飛ばされます。
  3. 楽器は付いていないので、各トラックに「Add Instrument...」でシンセを挿してください。音符はピアノロールでそのまま直せます。
  • テンポは、ファイル内の最初のテンポイベントがセッションのテンポに設定されます。曲の途中からのテンポ変更には追随しません。テンポイベントが無いファイルでは、現在のセッションのBPMがそのまま使われます。
  • 1つのトラック内に複数チャンネルが入っているファイルは、チャンネルを1本の音符列にまとめて読み込みます。ファイル内のCC（コントロールチェンジ）は取り込まれません。
  • SMPTE形式のタイムディビジョンを持つファイルは読み込めません（エラーが表示されます）。

MIDIキーボードで録音する

準備

  1. MIDIキーボードをPCに繋いでから、YM-Kitharaを起動します（起動時にMIDI入力デバイスが開かれます）。トランスポート行に「MIDI IN: 1 device: （名前）」と出れば認識しています。「MIDI IN: none」の場合は繋がっていません。
  2. Add MIDI Track でMIDIトラックを作り、いつもの手順で楽器を入れてください。
  3. 曲に合わせる場合は、先にテンポ（BPM）を曲に合わせてください。

録音のしかた

  1. そのMIDIトラックのヘッダーにある ●ボタン（アーム） を押します（M/Sボタンの右隣）。赤くなれば準備OKです。この時点で、止まったままキーボードを弾いても音が出ます（モニタリング。音色の確認にどうぞ）。
  2. トランスポートの REC ボタンを押すと、現在位置から再生が始まって録音されます（RECではなく Playを押しても、アーム中のトラックがあれば録音されます）。録音中はRECボタンが赤く点きます。
  3. 弾き終わったら Stop を押します。弾いた通りのクリップ（テイク）がトラックに出来上がります。そのままPlayを押せば、録った演奏が再生されます。
  4. 録ったクリップはダブルクリックでピアノロールが開き、いつも通り直せます。端ドラッグのトリムも効きます。
  • 何も弾かずにStopすると、クリップは出来ません（空のテイクは残らない仕様です）。
  • 音符を押さえたままStopしても大丈夫です。その音符は止めた位置までの長さで記録され、音も残りません。
  • ●は複数のトラックに同時に付けられます（同じ演奏がそれぞれのトラックに録音されます）。録音中に●を外すと、そのトラックの録音はその場で終わります。
  • アームの状態はプロジェクトに保存されません。プロジェクトを開き直すと全部外れているので、録音のたびに付け直してください（仕様です）。
  • 何も入っていないまっさらなプロジェクトでも、●を付ければそのまま録音できます。録音開始位置より先に何も無い場合は、セッションの終わりで止まらずに録音が続きます。
  • 音符のタイミングは、弾いた瞬間の時刻そのままで記録されます（機械側のポーリング時刻ではありません）。

現行版（v1）の録音の範囲：録音されるのは音符（ノートON/OFF）だけです。ペダルやホイールなどのCCは録音されません（CCでエフェクトを動かす「M→FX」は従来どおり使えます。「VST編」参照）。メトロノーム／カウントイン／クオンタイズ（タイミングの自動補正）／パンチイン・アウト／ループ録音も現行版にはありません。録ったままのタイミングで記録されます。

音が鳴りっぱなしになる心配について

停止・シーク（位置の移動）・曲の終わりのタイミングで、楽器へ「全音オフ」の信号が自動で送られます。弾いた音や再生中の音が鳴りっぱなしになることはありません。特別な操作（パニックボタン等）は不要です。

SRT編（歌詞テロップ）

SRTファイルを読み込む

  1. 上部の Import SRT... を押して .srt ファイルを選ぶか、ファイルをウィンドウへドラッグ＆ドロップします。
  2. テキストトラック（最大1本、無ければ自動で作られます）に、字幕のタイミング通りにテロップクリップが並びます。すでにクリップがある場合は末尾に追加されます（表示が重なった場合は、後から始まるテロップが勝ちます）。
  3. 読み込み結果は「○本追加、○本スキップ」と必ず表示されます。壊れたエントリ（時刻が読めない／終わりが開始以下／文字が空）はスキップされます。
  4. Video ボタンのプレビューで、テロップが出るか確認してください。映像の無い区間でも、黒画面の上にテロップだけは表示されます（歌詞だけの間奏など）。

読み込みは寛容に作られています：UTF-8 BOM、改行コードの違い、番号行の欠落、時刻の . 区切りやミリ秒の桁不足は吸収されます。<...> タグや {\...} の上書きブロックは取り除かれます。

テロップクリップの編集

  • テロップクリップは、他のクリップと同じように移動・トリム（端を伸ばし縮み）・分割・削除ができます。レーンには文字の1行目が表示されます。
  • 文字を直したいときは、クリップをダブルクリックするとテキスト編集ダイアログが開きます（複数行OK）。改行はそのまま表示され、行の自動折り返しはしません（SRTの行がそのまま行になります）。

見た目（スタイル）を変える

スタイルはセッション全体に1つの設定で、プロジェクトに保存され、プレビューとmp4書き出しの両方に同じ見た目で反映されます。

  1. テキストトラックのヘッダーにある Style... ボタンを押すと、設定ダイアログが開きます。
  2. 変更はその場でセッションに反映されるので、後ろのプレビュー画面がリアルタイムに追随します。ダイアログ下部にはサンプルテロップのプレビュー帯もあります。
  3. やっぱり戻したいときは Cancel（またはウィンドウを閉じる）で、開く前の状態に戻ります。OK で確定します。
項目内容
フォント「Choose...」から、PCにインストールされたフォントを名前で選択。一覧は名前だけを読み込むので、フォントが何百個あっても重くなりません。検索欄で絞り込め、選んだフォントでの見本（Aa Bb 123 あ ア 亜 歌）が表示されます。フォント未指定の場合は標準のサンセリフ太字です
サイズスライダーで 40〜250%。ヘッダーの Telop S / M / L（72% / 100% / 138% の目安）と連動しています
位置下部（標準）／中央／上部
揃え左／中央／右（行ごと。左・右のときは画面幅の4%の余白が付きます）
色プリセット7色（白・黄・シアン・緑・赤・マゼンタ・黒）＋「Custom...」で自由な色。縁取りは自動で、明るい文字には黒縁、暗い文字には白縁が付きます

メモ：選んだフォントがそのPCに無い場合（別のPCで作ったプロジェクトを開いた場合など）は、標準のフォントに置き換えて表示され、ピッカーやダイアログで「このPCには無い」旨が表示されます。プロジェクトが壊れることはありません。そのフォントをインストールすれば、本来の見た目に戻ります。

書き出しへの反映

テロップは Export MP4... で書き出したmp4にも、そのままのタイミング・見た目で焼き込まれます（映像の無い区間でも、黒画面の上にテロップだけが出ます）。

VST編（プラグイン）

YM-Kitharaが扱えるプラグインはVST3形式だけです。エフェクトはオーディオ／MIDI両方のトラックに、楽器はMIDIトラックに入ります。

最初に1回だけ：プラグイン探し（スキャン）

  1. 画面下部の Scan for Plugins... を押します。
  2. 別プログラム KitharaVstScanner.exe が起動して、PC内のVST3プラグイン（標準のインストール先 C:\Program Files\Common Files\VST3）を探します。終わると「〜 plugin(s) found.」と出ます。
  3. 結果はPC内に保存されるので、次回からは不要です（プラグインを新しく入れたら、もう一度スキャンしてください）。
  • スキャンはアプリの外（別プロセス）で走るので、壊れたプラグインがいてもDAW本体は落ちません。問題のあったプラグインファイルは、次回スキャンで先に飛ばされる仕組みになっています。
  • KitharaVstScanner.exe は YM-Kithara.exe と同じフォルダに必要です。無いとスキャンが始まらず、その旨のメッセージが出ます（本体の動作には影響しません）。

メモ：Windows自体にはVST3プラグインは付属していません。プラグインを何も入れていないPCでは、スキャンが終わっても一覧は空です（それで正常です）。Cakewalk Sonar付属のエフェクトなど、標準フォルダに入っているVST3は検出されます。

エフェクトの挿し方（FXチェーン）

  1. クリップをクリックして選ぶと、そのトラックが下部バーFX行の対象になります。
  2. Add FX... を押すと、スキャン済みプラグインの一覧（メーカー順）が出るので、選んで追加します。
  3. 音は挿した順に処理されます。各スロットには次のボタンがあります。
    • Open：プラグインの画面を別ウィンドウで開く
    • Bypass：そのエフェクトだけを一時的に無効化する
    • Remove：スロットを外す
  4. プロジェクトを保存すると、エフェクトの並び・バイパス状態・プラグイン内部の設定（ステート）も一緒に保存されます。

挿したエフェクト名は各トラックヘッダーにも「FX: 名前 > 名前」の形で表示されます（バイパス中は (off)、見つからない場合は (missing) の仮の行として残り、名前とステートは保持されます）。

楽器とエフェクトの違い

  • 楽器（シンセ）はMIDIトラックの楽器スロットに1つだけ入ります（入れ方は「MIDI編」）。楽器の後段には、通常のFXチェーンもそのまま挿せます。
  • エフェクトは全トラック共通のFXチェーンに入ります。オーディオトラックには楽器は入りません。

遅延の自動調整（PDC）

プラグインが報告する遅延をトラックごとに合計し、一番遅いトラックに合わせて他のトラックを遅らせることで、トラック同士のタイミングを自動で揃えます（プラグイン遅延補償＝PDC）。楽器の遅延もこの対象に含まれます。設定は不要で、プラグインの画面を閉じたタイミングでも再計算されます。

エフェクトをMIDIで操作する（M→FX）

MIDI対応エフェクト（モジュレーションホイールやペダルでパラメーターが動くタイプ）を、キーボード／コントローラーからリアルタイムで操作できます。

  1. MIDIキーボードやコントローラーをPCに繋いでから、YM-Kitharaを起動します（トランスポート行に「MIDI IN: 1 device: ...」と出れば認識しています）。
  2. 対象トラックのヘッダーにある M→FX ボタンをONにします。そのトラックのFXチェーンの全スロットへ、ライブのMIDI（CCなど）が届くようになります。
  3. 再生しながらコントローラーを動かします。

例：YM Mirage（v1.1）の場合、最初から次のように効きます。

操作効き方
モジュレーションホイール（CC1）PITCHが変わる
サスティンペダル（CC64）踏んでいる間 FREEZE
CC6564以上でエフェクトON、未満でOFF（バイパス）
  • 「M→FX」はトラックごとの設定で、プロジェクトに保存されます。OFFのトラックのエフェクトには届きません。
  • MIDIトラックでは、クリップの音符などのMIDIも後段のエフェクトに届きます。
  • WAV書き出しのときは、コントローラーのライブ操作は入りません（オフライン処理のため。仕様です）。MIDIトラックのクリップMIDIは書き出しでもエフェクトへ渡ります。

対応していない形式

注意：次の形式は使えません：VST2、AU、DirectXプラグイン（Sonitus等）、CakewalkのProChannelモジュール。標準フォルダ（C:\Program Files\Common Files\VST3）に入っている通常のVST3だけが対象です。

困ったとき

音が出ない
  • Audio Settings... で、出力装置が正しく選ばれているか確認してください。
  • トラックの M（ミュート）が押されていないか、S（ソロ）の付き方で他のトラックが消えていないか、トラック音量とトランスポート行の Volume（マスター音量）が下がりきっていないかを確認してください。
  • MIDIトラックは、楽器が入っていないと無音です。「Inst: (none)」のままになっていないか確認してください。
  • 動画トラック自体は音を出しません。動画の音を使いたいときは「Extract Audio」で取り込んでください（「動画（静止画）編」）。
プラグインが一覧に出てこない
  • まず Scan for Plugins... を1回押してください。プラグインを新しく入れたあとも、再スキャンが必要です。
  • KitharaVstScanner.exe が YM-Kithara.exe と同じフォルダにあるか確認してください（無いとスキャンできません）。
  • そのプラグインが標準フォルダ C:\Program Files\Common Files\VST3 に入っているか確認してください。VST2 / AU / DirectX形式のものは対象外です（「VST編」）。
  • PCにVST3が1つも入っていなければ、一覧が空なのが正常です。
プラグインが読み込めない／プロジェクトに「(missing)」と出る
  • そのプラグインがこのPCにインストールされているか確認し、Scan for Plugins... をやり直してください。
  • 「(missing)」は、そのプラグインが見つからない環境でプロジェクトを開いたときの仮の行です。名前と設定（ステート）は保持されているので、プラグインのある環境で開き直せば復帰します。
  • スキャン中に固まったプラグインは、次回のスキャンで先に飛ばされるようになります。スキャン自体が終わらない場合は、そのプラグインを標準フォルダから一時的に外して再スキャンしてください。
  • プラグインが大量にあるPCでは、スキャンに時間がかかることがあります（M6.10以降、進み具合はいま調べているプラグイン名で表示され、結果は1件ごとに保存されます）。途中で止まっても、見つかっていた分は一覧に入り、もう一度スキャンすれば続きから再開します。
  • それでもスキャンが完走しない場合は、手動スキャンもできます：YM-Kitharaを終了し、コマンドプロンプトで KitharaVstScanner.exe "<アプリデータ>\YM ORPHEUS\plugin-list.xml" を実行して Done と出るまで待ち、その後YM-Kitharaを起動し直してください。
動画が読み込めない／プロジェクトを開くと動画クリップが消える
  • 対応形式は mp4 / mov / mkv / m4v（静止画は jpg / jpeg / png / bmp）です。
  • 動画ファイルはプロジェクトにコピーされず、元の場所への参照だけが記録されます。元のファイルを移動・名前変更・削除すると、開くときに警告が出て、そのクリップだけ落ちます。ファイルを元の場所に戻すか、動画を読み込み直してください。
  • アプリ自体が起動しない場合は、exeと同じフォルダにFFmpegのDLL（avformat-*.dll など）が揃っているか確認してください（DLLが無いと起動しません）。
mp4書き出しが途中で止まる
書き出し前に全クリップの元ファイルをチェックします。見つからないファイルがあると、そのファイル名を表示して中止します。元の動画ファイルの場所を戻してから、もう一度書き出してください。
フォントが「このPCに無い」と出る
  • M6.7より前の版では、実際には入っているフォント（名前が日本語／英語の両方で登録されているもの等）が「無い」と判定されることがありました。最新版（M6.9）に更新してください。
  • 別のPCで作ったプロジェクトの場合、そのフォントが本当にこのPCへ入っていないことがあります。その場合は標準フォントで表示されます（壊れはしません）。フォントをインストールすれば本来の見た目に戻ります。
録音・打ち込みした音符の間隔がおかしい
音符は「拍」で記録されているため、音符を置いたあとでテンポ（BPM）を変えると、音符どうしの間隔が伸び縮みします。曲のBPMは Tempo 欄で先に合わせてから、音符を置く／録音するのが約束です（「MIDI編」）。すでに置いてしまった場合は、正しいBPMに戻すと間隔も元に戻ります。
キーボードを弾いても録音できない／「MIDI IN: none」と出る
  • MIDI入力デバイスは起動時に開かれます。キーボードを繋いでから、YM-Kitharaを起動し直してください。
  • 録音したいトラックの ●（アーム）が赤くなっているか確認してください。アームの状態は保存されないので、プロジェクトを開き直したら付け直しが必要です。
  • 何も弾かずにStopするとクリップは出来ません（空のテイクは残らない仕様です）。
ピアノロールで1小節より先が書けない
ピアノロールはクリップの長さぶんだけ表示されます。タイムライン上で、そのMIDIクリップの右端を右へドラッグして伸ばすと、ピアノロールも広がります（「MIDI編」のトリムの項）。
