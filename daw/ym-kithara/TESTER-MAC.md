# YM-Kithara（Mac版）テストのお願い

## YM-Kithara って何？

オーディオ編集・MIDI・VSTプラグイン・動画トラックまで扱える、音楽＆映像制作ワークステーション（DAW）です。
Suno AI で作った曲やステムを編集して、VST楽器を足したり、テロップ付きのMV（mp4）を書き出したりする用途で作っています。
今回はその **Mac版の初ビルド** です（Windows版 M6.10 と同じソース、Apple Silicon / Intel 両対応のユニバーサルバイナリ）。

## 起動方法

1. zip を解凍して、**"YM-Kithara.app"** を「アプリケーション」フォルダにコピーしてください。
2. **ターミナルで次のコマンドを1回実行してください。**
   このアプリは開発中のテスト版で、Appleの公証（ノータリゼーション）を受けていないため、この作業をしないと起動できません。

```
xattr -dr com.apple.quarantine "/Applications/YM-Kithara.app"
```

3. 初回だけ、アプリを **右クリック（または Control+クリック）→「開く」** で起動してください
   （警告ダイアログが出たら「開く」を選択）。次回からは普通にダブルクリックで開けます。
   ※ もし開けない場合は「システム設定 → プライバシーとセキュリティ」の下の方に「このまま開く」が出ます。

## 試してみてほしいこと

### 1. 起動と音
- [ ] アプリが起動するか
- [ ] メニューの「Audio Settings...」でお使いのオーディオ機器（インターフェース／ヘッドホン）が選べるか
      ※ Windows版の ASIO / WASAPI の代わりに、Mac では CoreAudio の機器が並びます

### 2. オーディオ編集
- [ ] 新規プロジェクトを作り、音声ファイル（WAV / MP3等）をタイムラインにドラッグ → 再生できるか
- [ ] クリップの移動・トリミング（端をドラッグ）・分割ができるか

### 3. 動画
- [ ] 動画ファイル（mp4等）をドラッグすると動画トラックに乗るか
- [ ] プレビュー表示と、クリップ下のフィルムストリップ（サムネイル帯）が出るか
- [ ] jpg / png の静止画もクリップとして置けるか（初期値5秒、ドラッグで伸縮できます）

### 4. VSTプラグイン
- [ ] 「Scan for Plugins...」でプラグインスキャンが最後まで終わるか
      ※ スキャナはアプリの中に同梱されています。スキャン中は今調べているプラグイン名が表示されます
- [ ] 別便の **YM-Effects-macOS.zip**（Echo / Mirage / Vortex / Choir）を入れた状態でスキャンし、
      どれか1つをトラックに読み込んで音が変わるか

### 5. MIDI（キーボードをお持ちなら）
- [ ] MIDIトラックに楽器プラグインを読み、トラックの ●（アーム）を押して鍵盤を弾くと音が出るか
- [ ] REC で演奏を録音するとクリップができるか
      ※ ノートを打ち始める前に、曲の BPM を先に合わせておくのがコツです

### 6. 書き出しと保存
- [ ] 短いタイムラインを mp4 で書き出せるか（動画＋音声）
- [ ] プロジェクトを保存 → 一度閉じて → もう一度開いて、内容がそのまま戻るか

## 正直なところ

Mac版は今回が初めてのビルドです。Windows版では安定していますが、Mac では初めて動かす部分
（CoreAudio、フォント周り、動画デコード等）が多いので、荒い所があるかもしれません。
「起動しない」「音が出ない」「ここで固まった」等、気づいたことは何でも、
できればスクリーンショット付きで教えてください。よろしくお願いします！
