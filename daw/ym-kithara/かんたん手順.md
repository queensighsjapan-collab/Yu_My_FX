# YM-Kithara かんたん手順（M6.10）

コマンドを打つ必要はありません。ビルド済みの方は、手順3からでOKです。

## 1. 道具を1つ入れる（最初の1回だけ）

**Visual Studio Community**（無料）を入れます。2026でも2022でもOKです。

- ダウンロード： https://visualstudio.microsoft.com/downloads/
  （「無料ダウンロード」の Community でOK）
- インストールの途中で「ワークロード」という画面が出たら、
  **「C++によるデスクトップ開発」にチェック**を入れて進めてください。
  あとから追加する場合は、Visual Studio Installer で「変更」→同じチェックを入れてください。

※ M0のときに済ませていれば、この手順は飛ばしてOKです。

## 2. ZIPを解凍する

`ym-orpheus-m3.zip` を右クリック →「すべて展開」。場所はどこでもOKです（デスクトップでも可）。

## 3. build.bat をダブルクリック

解凍したフォルダの中の **build.bat** をダブルクリックします。

- 黒い画面のまま数分〜十数分かかります（中身はフォルダ内の build-log.txt に書かれています）
- 最後に **Finished.** と出たら成功です。キーを押すと画面が閉じます

途中で [ERROR] が出て止まったら、フォルダ内の **build-log.txt** を私（マネージャー）に送ってください。直します。

## 4. アプリを開く

`build` → `YMKithara_artefacts` → `Release` → **YM-Kithara.exe** をダブルクリック。
画面左上のタグが **M6.10** になっていれば新しい版です。
（同じフォルダに **KitharaVstScanner.exe** も出来ています。これがプラグイン探し専用の小さいプログラムです。普段は触らなくてOKです）

## 動かし方（M1で増えたこと）

1. **曲を取り込む**：「Import File...」ボタン、またはファイルをウィンドウにドラッグ＆ドロップ。
   Sunoのステムを2〜3個入れてみてください。ファイルごとにトラックができて、波形が出ます
2. **鳴らす**：Playボタン。全部のトラックが一緒に鳴ります
3. **並べ替える・切る**：
   - クリップ（波形のブロック）をドラッグで移動。上下に動かすと別のトラックにも移せます
   - クリップの左右のはしをドラッグすると短くしたり伸ばしたりできます
   - Play中の縦線（再生ヘッド）をクリップの中に入れて、下の「Split at Playhead」を押すとそこで分割できます
   - いらないクリップは選んで Delete キー（または「Delete Clip」）
4. **音の入りをなめらかに**：クリップを選ぶと、下に Fade In / Fade Out が出ます。少し上げると音の頭がふわっと入ります
5. **トラックの操作**：左側の M（ミュート）/ S（ソロ）ボタン、小さい音量スライダー、名前はダブルクリックで変更、×でトラック削除
6. **場所を探す**：上の目盛り（ルーラー）をクリックすると、その場所から再生します。右下の Zoom で横の拡大が変わります
7. **保存する**：「Save Project...」でフォルダを選ぶと保存されます。
   アプリを閉じてから「Open Project...」でそのフォルダを選ぶと、同じ並びで戻ってきます

## 確認してほしいこと

- ステムを2つ以上入れて、同時に鳴るか
- 移動・トリム・分割・削除が効くか
- 保存して、開き直して、同じ配置に戻るか

結果を教えてください。次（M2：VSTエフェクト）に進みます。

## ASIOについて（あとで大丈夫）

ASIOで低遅延にしたい場合だけ、追加の部品（ASIO SDK）が要ります。まずはWASAPIのままで十分です。ASIO化は動いてから一緒にやりましょう。

## 追記：M1.1（音のブツブツ修正版）

再生中に音がブツブツ切れる問題を直した版です。原因は、画面の描画と
音声処理が「鍵（ロック）」を取り合って、音声側が負けた瞬間の音が
丸ごと消えていたことでした。音声側は鍵を使わない方式に作り替えたので、
画面を触っていても音が途切れなくなりました。

ZIP を解凍し直して、いつも通り build.bat をダブルクリックすれば OK です。
M1 で保存したプロジェクトはそのまま開けます。

## 追記：M1.2（再生の追従と Space キー）

操作の不便さを 2 つ直しました。

- **再生に画面がついてきます**：再生中、縦線（再生ヘッド）が画面の
  右端まで行くと、画面が自動でスクロールして線を追いかけるように
  なりました。止まっているときも、|< ボタンで先頭に戻ったり、
  ルーラーをクリックして線が画面の外に飛んだときは、画面が線の
  ところまでついてきます。線を動かさずに手でスクロールした場合は、
  勝手に動いたりしません。
- **Space キーで再生／停止ができます**：キーボードの Space を押すと
  Play / Pause が切り替わります。テンポの数字やトラック名を入力して
  いるときは、Space は文字入力のものになるので安心してください。

ZIP を解凍し直して、いつも通り build.bat をダブルクリックすれば OK です。
これまで保存したプロジェクトはそのまま開けます。

## 追記：M2（VST3エフェクトが使えるようになりました）

トラックごとに **VST3エフェクト**（リバーブやEQなど）を挿せるようになりました。

### 最初に1回だけ：プラグイン探し

1. 画面の下の方にある **「Scan for Plugins...」** ボタンを押します
2. 「Scanning...」の表示が出て、PCの中のVST3プラグインを探します
   （別プログラムが探すので、変なプラグインがあっても本体は落ちません）
3. 終わると「〜 plugin(s) found.」と出ます。これで準備OKです（毎回やる必要はありません）

### エフェクトの挿し方

1. クリップをクリックして選ぶと、そのトラックが下の「FX:」欄の対象になります
2. **「Add FX...」** を押すと、見つかったプラグインの一覧が出るので選んでください
3. 挿したエフェクトは **Open**（プラグインの画面を開く）、**Bypass**（一時的に無効化）、
   **Remove**（外す）ができます。音は挿した順にかかります
4. プラグインが遅延を持っていても、トラック同士がズレないよう自動で揃えます（PDC）
5. プロジェクトを保存すると、エフェクトの並びとプラグインの設定も一緒に保存されます

挿したエフェクトの名前は、**トラック名の下**にも小さく表示されます
（例：「FX: YM Echo > …」、バイパス中は名前に「(off)」が付きます）。
トラックの高さが小さいときは、この表示は出ません。

### 大事な注意

- Windows には最初から VST3 プラグインは **1つも入っていません**。
  プラグインを何も入れていないPCだと、スキャンしても一覧は空っぽになりますが、
  **それで正常です**（壊れているわけではありません）
- かいさんのPCなら、Cakewalk Sonar に付いてきたエフェクトのうち、
  標準の場所（`C:\Program Files\Common Files\VST3`）に入っているものは見つかります
- 自作のシンセ（楽器プラグイン）も一覧には出ます。ただ、MIDIで鳴らすのは次のM3です。
  今回はエフェクト処理が主役です

### ついでに入ったもの：縦ズーム

右下に **V Zoom** スライダーが増えました。トラックの高さを変えられます
（タイムラインの上で Ctrl＋マウスホイールでも変わります）。

ZIP を解凍し直して、いつも通り build.bat をダブルクリックすれば OK です。
これまで保存したプロジェクトはそのまま開けます。

### 修正のお知らせ（プラグインが読み込めない不具合）

最初にお渡しした M2 では、**どのプラグインを選んでも
「Could not load the plugin ...」になってしまう不具合**がありました。
この版で直っています。もう一度 build.bat で作り直してからお試しください。
前に保存したプロジェクトも、そのまま開けば直る見込みです。

## 追記：M3（MIDIと楽器が使えるようになりました＋WAV書き出し）

シンセ（VST楽器）を **MIDIで鳴らせる** ようになりました。
あと、曲全体を **WAVファイルに書き出す** 機能も入りました。

### 大事なこと：先にテンポ（BPM）を合わせてください

音符は「拍」で覚えているので、**音符を置いたあとでテンポを変えると、
音符どうしの間隔が伸び縮み** してしまいます。
まず上のテンポ欄を曲のBPMに合わせてから、音符を置いてください。

### 楽器を鳴らす手順

1. 上の **「Add MIDI Track」** ボタンを押すと、MIDIトラックが増えます
2. MIDIトラックのレーン（何もない所）を **ダブルクリック** すると、
   その小節に **MIDIクリップ**（青緑のブロック）ができます
3. できたクリップをクリックして選ぶと、下のFX欄の左側に
   **「Inst: (none)」** と出るので、**「Add Instrument...」** を押して
   楽器（シンセ）を選んでください
   （一覧が空なら、先に「Scan for Plugins...」を1回押してください。
   一覧に出るのは楽器だけです）
4. クリップを **ダブルクリック** すると **ピアノロール** が開きます
5. ピアノロールでは：
   - 空いているマスをクリック → 音符が置けます
   - 音符はドラッグで移動（上下＝音程、左右＝タイミング）
   - 音符の右はしをドラッグすると長さが変わります
   - いらない音符は、選んで Delete キー、または右クリックで削除
6. ウィンドウを閉じて **Play** を押すと、置いた通りに楽器が鳴ります
7. 楽器の画面は「Open Inst」で開けます。外すときは「Remove Inst」
8. MIDIトラックにも、今まで通り「Add FX...」でエフェクトが挿せます
   （楽器の音にかかります）

### WAVに書き出す

1. 上の **「Export WAV...」** ボタンを押します
2. 保存する場所とファイル名を選んで保存（最初は mixdown.wav になっています）
3. 少し待つと書き出し完了。下のメッセージに「Exported: 〜」と出ます
4. 書き出したWAVには、曲の終わりに2秒の余韻がくっついています

### 確認してほしいこと

- かいさんの自作シンセを楽器に選んで、ピアノロールで置いた通りに鳴るか
- 止めたときに音が残らないか（鳴りっぱなしにならないか）
- 保存して開き直すと、楽器と音符が戻ってくるか
- 書き出したWAVが、ほかのプレイヤーでちゃんと再生できるか

ZIP を解凍し直して、いつも通り build.bat をダブルクリックすれば OK です。
これまで保存したプロジェクトはそのまま開けます。

## 追記：M3.1（MIDIファイルを読み込めるようになりました）

ピアノロールで打ち込む代わりに、**MIDIファイル（.mid）をそのまま読み込める** ようになりました。

### 手順

1. 上の **「Import File...」** を押して `.mid` ファイルを選ぶ
   （ウィンドウにドラッグ＆ドロップでもOKです）。音源ファイルと混ぜて選んでも大丈夫です
2. ファイルの中の **音符のあるトラックごとに、MIDIトラックが1本ずつ** できます。
   音符は先頭のクリップに全部入っています
3. テンポは、ファイルに記録されている **最初のテンポ** が自動でセッションに設定されます
   （下のメッセージに「Imported MIDI: 〜 tracks, tempo 〜 BPM」と出ます）
4. 楽器は付いていないので、各トラックのクリップを選んで
   **「Add Instrument...」** でシンセを挿してください
5. 音符はピアノロールでそのまま直せます

### 注意

- 1つのトラックの中に複数チャンネルが入っているファイルは、
  チャンネルをまとめ読みします（音符は全部残ります）
- 曲の途中でテンポが変わるファイルは、最初のテンポのまま読み込みます

各トラックの右端と、上の「MASTER」に **音量メーター** が付きました。

音量を下げて調整し、ランプはクリックすると消えます。

## 追記：M3.3（エフェクトをMIDIで操作できるようになりました＋左端が固定されました）

### その1：コントローラーでエフェクトを動かす

YM Mirage みたいな **MIDI対応エフェクト** を、ORPHEUS の中でも
キーボード／コントローラーから動かせるようになりました。

1. MIDIキーボードやコントローラーをPCに繋いでから、ORPHEUS を起動します
   （上の行に **「MIDI IN: 1 device: …」** と出れば認識しています。
   「MIDI IN: none」なら繋がっていません）
2. エフェクトを挿したトラックの左端にある **「M→FX」** ボタンを押してONにします
3. 再生しながらコントローラーを動かします

YM Mirage なら、最初からこう効くようになっています：

| 操作 | 効き方 |
|---|---|
| モジュレーションホイール（CC1） | PITCHが変わる |
| サスティンペダル（CC64） | 踏んでいる間 FREEZE |
| CC65 | 64以上でエフェクトON、未満でOFF（バイパス） |

- 「M→FX」はトラックごとの設定で、プロジェクトに保存されます
- OFFのトラックのエフェクトには届きません
- MIDIトラックでは、クリップの音符などのMIDIも後ろのエフェクトに届きます
- WAV書き出しのときは、コントローラーの操作は入りません（オフライン処理のため）

### その2：左端のトラック名の列が固定されました

タイムラインを右へスクロールしても、**左端の列（トラック名・M・S・M→FX・
音量・メーター）が残る** ようになりました。スクロールするのは波形だけです。
上下のスクロールは今まで通り、左端と波形が揃って動きます。

## 追記：M6（動画トラックが付きました＋アイコンが変わりました）

ミュージックビデオ作りの土台として、**動画を読み込んで、曲に合わせて
再生・カット編集** できるようになりました。ついでにアプリアイコンが
**金のリラ（竪琴）** に変わりました。タスクバーのアイコンで見分けてください。

### 最初のビルドだけ、少し長くかかります

build.bat の初回だけ、動画再生に使う **FFmpeg（約90 MB）を自動で
ダウンロード** します。ネットに繋いだまま待ってください（2回目以降は
ダウンロードしません）。終わると、exe の隣に avformat-*.dll などの
ファイルが並びます（消さないでください）。

### 動画を読み込む

1. 上の **「Add Video...」** ボタンを押して、mp4 ファイルを選びます
   （タイムラインへドラッグ＆ドロップでもOK。スマホで撮った動画で大丈夫です）
2. 動画トラックができて、レーンに **フィルムのようなサムネイル** が
   並びます（絵が出るまで少し待ってください）
3. もう1本読み込むと、後ろにくっついて追加されます（動画トラックは1本だけです）

### 映像を見ながら再生する

1. 上の行の **「Video」** ボタンを押すと、プレビューの小窓が開きます
2. Play を押すと、曲に合わせて映像が動きます。止めれば止まります
3. 止めたままルーラーをクリックすると、その場所の映像に切り替わります
4. 閉じるときは小窓の × か、もう一度「Video」ボタンを押します

### 切り貼りする

オーディオのクリップと同じ操作です。

- ドラッグで移動、両端をドラッグで短く／長く（元の動画の範囲まで）
- クリップを選んで、再生ヘッドの位置で **Split** を押すとそこで切れます
- Delete キーで消えます

### タイムコード

上の行に **タイムコード（00:00:00:00 の形）** が出るようになりました。
動画を読み込むと、その動画のフレームレートに自動で合います
（29.97 の動画なら `00:00:00;00` のように `;` 区切りになります）。
右隣のプルダウンで手動で変えることもできます。

### 注意

- **動画ファイル自体の音は鳴りません**。音はいつも通りオーディオ
  トラック側で用意してください（Suno の曲を読み込んで合わせる想定です）
- プロジェクトには動画ファイルの場所だけが記録されます。**元の動画
  ファイルを移動・削除すると、そのクリップは開けなくなります**
  （警告が出て、クリップだけ落ちます）

## 追記：M6.2（mp4に書き出せるようになりました）

切り貼りした動画と曲を、**1本の mp4 ファイル** に書き出せるように
なりました。ミュージックビデオの完成形が作れます。

### 書き出し方

1. 上の **「Export MP4...」** ボタンを押します
   （動画トラックが無いと「先に動画を読み込んで」と案内が出ます）
2. 設定の小窓が出ます。最初はそのままで大丈夫です
   - **Picture size**：Original（元の動画の大きさ）がおすすめ。
     1080×1920 を選ぶと **縦動画（Shorts／TikTok 用）** になります
     （横動画は上下に黒い帯が付いて、比率はそのまま保たれます）
   - **Quality**：Standard がおすすめ。High はきれいだけどファイルが
     大きく、Light は軽いけど少し粗くなります
3. 保存先とファイル名を決めると書き出しが始まります（進み具合の
   バーが出ます）。**途中でキャンセルもできます**。その場合、
   書きかけのファイルは残りません

### 知っておくと安心なこと

- 書き出しの長さは **WAV書き出しとまったく同じ**（曲の長さ＋2秒の
  余韻）です。映像の無いところは黒画面で、音だけが流れます
- 書き出し前に元の動画ファイルの場所をチェックします。**移動・削除
  したファイルがあると、その名前を表示して中止** します
- 書き出した mp4 は、普通の動画プレイヤーやスマホでそのまま
  再生できます（配信で使われる方式で記録しています）

### 小さいモニターが付きました

動画トラックがある間は、画面右上（タイムラインの隅）に **小さい
モニター** がずっと出ています。再生やシークに合わせて絵が動きます。
**クリックすると大きいプレビュー画面が開きます**（絵はどちらも
まったく同じものです）。

### 動画の音声を取り込めます（Extract Audio）

動画ファイルに入っている音（スマホ動画の環境音など）を、普通の
オーディオトラックとして取り込めます。

1. 上の **「Extract Audio」** ボタンを押します（少し待ちます）
2. **「（動画の名前） Audio」** というトラックが増えて、映像の
   クリップと **場所・長さがぴったり同じ** 音声クリップが並びます
3. あとは普通のトラックと同じです。その音だけ消したいときは
   トラックをミュート、残したいときはそのまま使えます

- 音声は動画ファイルの隣に「（動画の名前）_audio.wav」という
  ファイルで保存されます（プロジェクト保存でも一緒に保存されます）
- もう一度押してもトラックは増えません（「取り込み済み」と出ます）
- 音の入っていない動画は、その名前を表示してスキップします

## 追記：M6.3（動画のクロスフェードと歌詞テロップ＋フリーズ対策）

### mp4読み込みで固まる問題への対策

M6.2 で「mp4を読み込むとフリーズする」と教えてもらった件、原因に
なりそうなところを全部つぶしました。あわせて、画面右上の小さい
モニターは **無くしました**（プレビューは今まで通り **VIDEOボタン** の
大きい画面だけです）。このモニターが「読み込み直後から映像の
読み取りを始める」仕掛けだったので、無くしたことで **動画を
読み込んだだけでは何も始まらない**（最初のバージョンと同じ）動きに
戻っています。まずは、前に固まった mp4 をもう一度読み込んで
みてください。

### 動画クリップ同士をなめらかにつなげます（クロスフェード）

- 動画クリップは **重ねて置ける** ようになりました（動画トラック
  だけ）。重なった部分では、前の映像から次の映像へ **ゆっくり
  切り替わります**（クロスディゾルブ）
- クリップ単体のフェードも付けられます。クリップの **左上の角を
  右にドラッグ** するとフェードイン、**右上の角を左にドラッグ**
  するとフェードアウトです。フェードが付いた部分には三角の
  陰影が付きます。下に映像が無いところでは、黒から／黒への
  フェードになります
- プレビューでも、書き出した mp4 でも、同じ見え方になります

### 歌詞テロップを入れられます（SRT読み込み）

字幕ファイル（.srt）を読み込むと、歌詞などの文字を映像の下に
自動で表示できます。

1. 上の **「Import SRT...」** ボタンを押して .srt ファイルを
   選びます（ファイルを画面にドラッグ＆ドロップでもOK）
2. **「Text」トラック** が増えて（無ければ自動で作られます）、
   字幕のタイミング通りに **テロップクリップ** が並びます。
   「○本追加しました」と出ます。壊れた字幕があったら、その数も
   一緒に教えてくれます（壊れた分は飛ばされます）
3. **VIDEOボタン** のプレビューで、歌詞が出るか確認してください。
   映像が無いところでも、黒画面に文字だけ出ます

- テロップクリップは、他のクリップと同じように **移動・端を
  伸ばし縮み・分割・削除** ができます
- 文字を直したいときは、クリップを **ダブルクリック** すると
  編集画面が出ます（改行もそのまま表示されます）
- 文字の大きさは、Textトラックの左側にある **「Telop S / M / L」**
  で変えられます
- 書き出した mp4 にもテロップがそのまま入ります

## 追記：M6.6（テロップの見た目を変えられるようになりました）

テロップの **フォント・位置・揃え・色・サイズ** を、まとめて変えられる

- テキストトラックの **「Style...」ボタン** を押すと設定画面が開きます

## 追記：M6.8（MIDIキーボードで録音できるようになりました）

MIDIキーボードを **弾いて、そのまま録音** できるようになりました。
弾いた演奏はMIDIクリップになって残るので、あとからピアノロールで
直すこともできます。

### 準備

1. MIDIキーボードをPCに繋いでから、YM-Kithara を起動します
   （上の行に **「MIDI IN: 1 device: …」** と出れば認識しています）
2. **「Add MIDI Track」** でMIDIトラックを作り、いつもの手順で
   **楽器（YM2000 など）を入れて** ください
3. 曲に合わせる場合は、先に **テンポ（BPM）を曲に合わせて** ください
   （音符は「拍」で覚えるので、ピアノロールのときと同じ約束です）

### 録音のしかた

1. そのMIDIトラックの左端にある **●ボタン（アーム）** を押します。
   赤くなれば準備OKです。**この時点で、止まったままキーボードを
   弾いても音が出ます**（音色の確認にどうぞ）
2. 上の **RECボタン** を押すと、再生が始まって録音されます
   （RECではなく **Playを押しても、アーム中なら録音されます**）
3. 弾き終わったら **Stop** を押します。弾いた通りの **クリップ** が
   トラックに出来上がります
4. そのまま Play を押せば、録った演奏が再生されます

### 知っておくと安心なこと

- **何も弾かずに Stop すると、クリップは出来ません**（空のテイクは
  残らない仕様です）
- ノートを **押さえたまま Stop** しても大丈夫です。そのノートは
  止めた位置までの長さで記録され、音も残りません
- 録ったクリップは **ダブルクリックでピアノロール** が開いて、
  いつも通り直せます
- ●は **複数のトラックに同時に** 付けられます（同じ演奏が両方に
  録音されます）
- 録音中に ●を外すと、そのトラックの録音はその場で終わります
- **アームの状態は保存されません**。プロジェクトを開き直すと
  全部外れているので、録音のたびに付け直してください（仕様です）
- 何も入っていない **まっさらなプロジェクトでも**、●を付ければ
  そのまま録音できます

### 今回は入っていないもの（今後の候補）

- メトロノームとカウントイン
- クオンタイズ（タイミングの自動補正）。録ったままのタイミングで
  記録されます
- **CC（ペダルやホイール）の録音**。録音されるのは音符だけです
  （CCでエフェクトを動かす「M→FX」は今まで通り使えます）

確認のお願い：楽器を入れたMIDIトラックに ●を付けて、止まったまま
弾いて鳴ること、Record で弾いて Stop するとクリップができること、
それが再生されること、ピアノロールで開けることを見てみてください。
弾いた感じと録音のタイミングに違和感がないかも教えてください。

## 追記：M6.10（プラグイン探しが最後まで終わるようになりました）

プラグインをたくさん入れているPCだと、前の版では「Scan for
Plugins...」が途中で止まってしまい、いつまで待っても終わらない
ことがありました。直しました。

- **時間はかかっても、最後まで探します**：プラグインが多いと
  スキャンに時間がかかるのは普通です。いま調べているプラグインの
  名前が画面に出るので、進んでいるかどうか分かります
- **途中で止まっても大丈夫です**：探した結果は1件ごとに保存されて
  いるので、途中でアプリを閉じたり、固まったプラグインがあって
  止まったりしても、**もう一度スキャンすれば続きから** 進みます
  （最初からやり直しにはなりません）。止まった時に見つかっていた
  プラグインは、その時点で一覧に入ります
- **どうしても終わらない時は**：アプリを終了して、コマンドプロンプトで
  `KitharaVstScanner.exe "<アプリデータ>\YM ORPHEUS\plugin-list.xml"`
  を実行し、`Done` と出るまで待ってから、アプリを起動し直してください
  （詳しくは README の「スキャナを手動で走らせる方法」を見てください）

確認のお願い：プラグインがたくさんある環境でスキャンが最後まで
終わること、スキャン中にプラグイン名が切り替わって出ることを
見てみてください。
