# YM Choir — ボイス・マルチプライヤー VST3（v1.0.0）

1 人の声を合唱団に変える VST3 エフェクトプラグインです。
入力の Mid 信号を 1 秒のリングバッファーに書き込み続け、最大 8 声の
「コーラス隊」が、古典的なデュアルタップ・クロスフェード式の
ピッチシフターでそれを読み返します。各声は固定のデチューン、
タイミングのずれ、ビブラート、パン、音色を持っていて、
原音（Dry）の上に重なることで「何人かで一緒に歌っている」厚みが
生まれます。自作コードのみで実装しています。

Cakewalk Sonar、YM ORPHEUS など、一般の VST3 ホストで使えます。

## 正直な注記：これは「ユニゾンの厚み」であって、ハーモニー生成ではありません

各コピーは **元の音程のまま**（±数十セントのデチューンのみ）です。
3 度や 5 度といった和音の声部は作りません。1 人の歌が
「複数人で歌っているように聞こえる」ようにする効果です。
ハーモニーが欲しい場合は DAW 側で別トラックに歌う／打ち込む必要があります。

## 仕組み

| 段 | 内容 |
|---|---|
| リングバッファー | 入力ステレオの Mid 信号（(L+R)/2）を 1 秒のリングバッファーに常時書き込み。**Dry 経路はステレオのまま**で、コーラス隊だけが Mid から作られ、パンで左右に再配置されます |
| ピッチシフター | 声ごとに古典的なデュアルタップ方式。半ウィンドウずれた 2 本の読みタップを Hann（sin²）重みでクロスフェード（重みの和は常に 1）。鋸波フェーズが (ratio − 1) / ウィンドウ長 で進むことでピッチが変わります。ウィンドウ長は 48 kHz で 4096 サンプル（約 85 ms、ホストのサンプルレートで換算）で、声にちょうど良い粒の大きさです |
| 声のキャラクター | 声番号から決まる **固定パターン**（実行時の乱数はなし）。デチューンは DETUNE ノブ量に対する割合で ±側に散らばり、タイミングは TIMING ノブ量に対する割合の遅れ、ビブラートは声ごとに 3.5–6.5 Hz の固定レートを持ちます |
| ビブラート | 深さは VIBRATO ノブで最大 ±15 セント。各声で位相が違うので、コーラス全体がうねります |
| 配置と音色 | 声はセンターから外側へ等間隔に配置され、SPREAD で広がります（等パワー・パン）。センターの声は少し大きめ、外側の声は少し暗め（声ごとの 1 ポール・ローパス）。全体に TONE ノブの傾き（4–16 kHz）がかかります |
| レベル補正 | 声のゲインは 1/√（有効な声数）で正規化。VOICES を増やしても音量が暴れません。声の増減は約 30 ms のフェードで切り替わるのでクリックは出ません |

### レイテンシーについて

タップは書き込みヘッドより最大で「ウィンドウ長 ＋ タイミング分」
だけ後ろを読みます。本プラグインは **ウィンドウ長（48 kHz で
4096 サンプル ≒ 85 ms）をホストにレイテンシーとして報告** します。
YM ORPHEUS のような自動遅延補償（PDC）を持つホストでは Dry と
Wet のタイミングが揃います。

### テイル

申告テイルは **0.3 秒** です（タップの読み遅れ＋ローパスの残り分）。

## パラメーター

| パラメーター | 範囲 | 初期値 | 内容 |
|---|---|---|---|
| Voices | 1–8 | 4 | 重ねるコーラスの声数（Dry は含まない） |
| Detune | 0–60 cents | 18 cents | 声ごとのデチューンの散らばり幅 |
| Timing | 0–30 ms | 12 ms | 声ごとのタイミングのずれ幅（人間っぽいゆるさ） |
| Vibrato | 0–1 | 0.4 | 声ごとのビブラートの深さ（最大 ±15 セント） |
| Spread | 0–1 | 0.7 | 声の左右の広がり。0 で全員センター |
| Tone | −1–+1 | 0 | コーラス隊全体のローパスの傾き |
| Mix | 0–1 | 0.45 | Dry / コーラス隊のブレンド。0 で原音のみ |
| Output | −24–+12 dB | 0 dB | 出力ゲイン |

## MIDI CC バイパス（YM 標準仕様）

かいさんの指定（2026-11-10）により、YM のエフェクトはすべて
MIDI CC で ON/OFF できるのが標準仕様です。

- **Bypass CC（初期値 65）**：値 64 以上でエフェクト ON、
  64 未満でバイパス（ペダル式）
- 画面左下の **ON / BYPASS ボタン**、ホストのバイパスボタンとも連動
- 切り替えは約 15 ms のクロスフェードでクリックなし。
  バイパス中もバッファーへの書き込みは続くので、戻したときに
  古い音が蘇ることはありません
- **LEARN** ボタンを押してからコントローラーを動かすと、その CC
  番号に付け替えられます（LEARN の右クリックで割り当て解除 = Off）。
  CC 0 は「Off」の意味に使うため割り当てできません
- 割り当てはプラグインの状態として保存されます

注意：プラグイン側は MIDI を受けられますが、**ホスト側で
エフェクトへの MIDI 送信を有効にする**必要があります
（YM ORPHEUS では現状この経路は未対応です）。

## ビルドとインストール

1. フォルダー内の **build.bat** をダブルクリック（初回は JUCE の
   ダウンロードで数分かかります）
2. `build → YMChoir_artefacts → Release → VST3` にできる
   **YM Choir.vst3 フォルダーごと** を
   `C:\Program Files\Common Files\VST3` にコピー
3. ホスト側でプラグインの再スキャンを実行

詳しい手順は同梱の「かんたん手順.md」を見てください。

## 聴き方のチェックポイント

- ソロボーカルに VOICES 4 / DETUNE 18 / TIMING 12 / MIX 45%:
  1 人の声が小さな合唱団に聞こえるか
- VOICES 8 / DETUNE 30 前後: 大編成の厚みになるか
  （上げすぎると「ケロケロ」感が出るので注意）
- SPREAD 0 ↔ 1: 全員センター（モノラル）↔ 左右いっぱいの
  広がりが切り替わるか
- VIBRATO を 0 → 大：声のうねりが増えて「生っぽさ」が出るか
- ギターやシンセにも：単音のフレーズが太く聞こえるか
  （コード入力では各音が増殖するので MIX は控えめがおすすめ）
