# YM Choir かんたん手順（v1.0.0）

1 人の声を合唱団みたいに厚くするエフェクトです。
声のコピーを何人分も作って、音程とタイミングを少しずつずらして
重ねます。作り方は YM Echo / YM Orbit / YM Mirage と同じ要領です。

## 1. ビルドする

フォルダーの中の **build.bat** をダブルクリックしてください。

- 黒い画面が出て、自動で進みます
- 初回だけ部品（JUCE）のダウンロードで数分かかります
- 最後に **DONE!** と出たら成功です

途中で [ERROR] が出て止まったら、同じフォルダーにできる
**build-log.txt** をマネージャーに送ってください。

## 2. プラグインを所定の場所に置く

ビルドが終わると、フォルダーの中に

```
build → YMChoir_artefacts → Release → VST3 → YM Choir.vst3
```

という**フォルダー**ができています（ファイルじゃなくてフォルダーです）。

この **YM Choir.vst3 フォルダーごと**、下の場所にコピーしてください。

```
C:\Program Files\Common Files\VST3
```

※ コピーのとき管理者権限の確認画面が出ます。「続行」でOKです。

## 3. DAW で試す

1. YM ORPHEUS（または Cakewalk Sonar）を起動
2. 初回は **Scan for Plugins...** を実行
3. ボーカルなどのトラックの FX に **YM Choir** を挿す

## 4. 使い方の例

### ソロボーカルを合唱団に（おすすめの出発点）

- VOICES: **4**
- DETUNE: **18 ct**
- TIMING: **12 ms**
- VIBRATO: 40%
- MIX: **45%**

1 人で歌った声が、4 人の合唱隊を従えたように聞こえます。

### 大編成コーラス

- VOICES: **8**
- DETUNE: 30 ct くらい
- TIMING: 20 ms
- SPREAD: 90%
- MIX: 50%

ゴスペルっぽい厚みになります。DETUNE を上げすぎると
音程がふらついて聞こえるので、30 前後が心地よい範囲です。

### さりげない厚み（ダブリング風）

- VOICES: **2**
- DETUNE: 8 ct
- TIMING: 6 ms
- MIX: 25%

「エフェクトかけた感」は薄く、声だけ太くなります。
ナレーションやラップにも。

### 注意

これは「同じ音程のコピーを重ねる」エフェクトです。
ハーモニー（3 度上・5 度上などの和音）は作りません。
和音が欲しいときは、DAW 側で和音のトラックを別に用意してください。

## 5. MIDI で ON/OFF する（YM 標準仕様）

- 初期設定では **CC 65** で ON/OFF できます
  （値 64 以上 = ON、64 未満 = バイパス）
- 画面の **LEARN** ボタンを押してから、使いたいペダルや
  コントローラーを動かすと、その番号に付け替えられます
- LEARN を **右クリック** すると割り当て解除（Off）です
- 画面左下の ON / BYPASS ボタンでも切り替えられます

※ ホスト（DAW）側で「エフェクトへ MIDI を送る」設定が
必要な場合があります（YM ORPHEUS では現状未対応）。

## つまみの意味（英語表示のまま）

| 表示 | 意味 |
|---|---|
| VOICES | 重ねる声の数（1–8） |
| DETUNE | 声ごとの音程のずれ幅（セント単位） |
| TIMING | 声ごとのタイミングのずれ幅 |
| VIBRATO | 声ごとのビブラートの深さ |
| SPREAD | 声の左右の広がり。0 で全員真ん中 |
| TONE | コーラス隊の明るさ（右で明るく、左で暗く） |
| MIX | 原音とコーラスの混ぜ具合 |
| OUTPUT | 全体の音量 |
