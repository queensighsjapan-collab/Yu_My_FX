# YM Choir（Mac版）テストのお願い

## YM Choir って何？

1本の音に最大8本の声を重ねて厚くする「声増幅」エフェクト（VST3プラグイン）です。デチューンとタイミングのズレ、個別のビブラートで、コーラスのような膨らみを作ります（ハモリ生成ではなく、ユニゾンの厚み付け専用です）。
Apple Silicon / Intel 両対応のユニバーサルバイナリです。

## インストール方法

1. zip を解凍して、**"YM Choir.vst3"** を次のフォルダにコピーしてください
（管理者パスワードを求められます）

```
/Library/Audio/Plug-Ins/VST3/
```

※ ユーザーフォルダ配下の `~/Library/Audio/Plug-Ins/VST3/` でも大丈夫です。

2. **ターミナルで次のコマンドを1回実行してください。**
このプラグインは開発中のテスト版で、Appleの公証（ノータリゼーション）を受けていないため、この作業をしないとDAWに読み込まれません。

```
xattr -dr com.apple.quarantine "/Library/Audio/Plug-Ins/VST3/YM Choir.vst3"
```

※ `~/Library/...` に入れた場合はこちらです：

```
xattr -dr com.apple.quarantine "$HOME/Library/Audio/Plug-Ins/VST3/YM Choir.vst3"
```

3. DAWを再起動（またはプラグインの再スキャン）をして、適当なトラックに **"YM Choir"** を挿してください。

## 聴いてみてほしいポイント

素材はボーカルやシンセが分かりやすいです。

1. **VOICES**：声の数が増えると厚くなるか（最大8本）。
2. **DETUNE / TIMING / SPREAD**：デチューンの量、タイミングのズレ、左右の広がりが変わるか。
3. **TONE**：音色の傾きが変わるか。ノイズや音切れがないか。
4. **Bypass**：MIDI CC65（既定）やパネルのON/OFFで、音が途切れず切り替わるか。

気づいたこと（鳴らない、画面が変、効果が弱い/強すぎる等）があれば、スクリーンショットや録音と一緒に教えてください。よろしくお願いします！
