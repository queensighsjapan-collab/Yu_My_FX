# YM Mirage かんたん手順（v1.1.0）

音を細かい粒に刻んで、霧みたいにぼかして返すエフェクトです。
FREEZE ボタンを押すと、その瞬間の音が無限に伸びるパッドになります。
作り方は YM Echo / YM Orbit と同じ要領です。

## 1. ビルドする

フォルダーの中の **build.bat** をダブルクリックしてください。

- 黒い画面が出て、自動で進みます
- 初回だけ部品（JUCE）のダウンロードで数分かかります
- 最後に **DONE!** と出たら成功です

途中で [ERROR] が出て止まったら、同じフォルダーにできる
**build-log.txt** をマネージャーに送ってください。

## 2. プラグインを所定の場所に置く

ビルドが終わると、フォルダーの中に

```
build → YMMirage_artefacts → Release → VST3 → YM Mirage.vst3
```

という**フォルダー**ができています（ファイルじゃなくてフォルダーです）。

この **YM Mirage.vst3 フォルダーごと**、下の場所にコピーしてください。

```
C:\Program Files\Common Files\VST3
```

※ コピーのとき管理者権限の確認画面が出ます。「続行」でOKです。

## 3. DAW で試す

1. YM ORPHEUS（または Cakewalk Sonar）を起動
2. 初回は **Scan for Plugins...** を実行
3. トラックの FX に **YM Mirage** を挿す

## 4. 使い方の例

### キラキラした霧（シマー・クラウド）

ボーカルやピアノのトラックに挿して：

- SIZE: 80–150 ms
- PITCH: **+12 st**
- DENSITY: 50% くらい
- MIX: 50%

声や音の上に、1オクターブ上の霧がふわっとかかります。

### 無限パッド（FREEZE）

1. コードや声が鳴っているところで再生
2. いい響きの瞬間に **FREEZE** ボタンを押す
3. 元の音を止めても、つかまえた響きがずっと鳴り続けます

Suno のボーカルの一瞬を凍らせて、そのまま曲の土台のパッドにできます。
FREEZE 中も粒は動き続けるので、完全な静止画じゃなく
ゆっくり息づくような持続音になります。

### 重くて暗い雲

- PITCH: **−12 st**
- SIZE: 150–200 ms
- SMEAR: 大きめ

低く沈んだ、時間の滲んだ雲になります。ベースや SE にも。

## つまみの意味（英語表示のまま）

| 表示 | 意味 |
|---|---|
| SIZE | 粒の長さ。短い = 粒々、長い = なめらか |
| DENSITY | 粒の数。多いほど濃い雲 |
| PITCH | 粒の音程（半音単位、±12） |
| SPREAD | 粒の左右の広がり。0 で真ん中だけ |
| SMEAR | 粒が拾う位置のばらつき。大きいほど時間が滲む |
| MIX | 原音とエフェクトの混ぜ具合 |
| OUTPUT | 全体の音量 |
| FREEZE | 音を凍らせて無限に持続させるボタン |
| ON / BYPASS | エフェクトの入／切ボタン（ON のとき点灯） |

## 5. MIDI コントローラーで操作する（v1.1 の新機能）

キーボードやコントローラーのツマミ・ペダルで、PITCH・FREEZE・
ON/OFF を操作できます。最初からこう割り当てられています：

| 操作 | 最初の割り当て |
|---|---|
| PITCH | CC 1（モジュレーションホイール） |
| FREEZE | CC 64（サステインペダル）…踏んでいる間だけ凍ります |
| ON/OFF | CC 65…値が大きいと ON、小さいとバイパス |

### 割り当てを変えたいとき（MIDI ラーン）

1. 画面の下のほうにある **LEARN** ボタン（PITCH / FREEZE / BYPASS の
   どれか）を押します（ボタンが光ります）
2. 使いたいコントローラーのツマミやペダルを動かします
3. その番号が割り当てられて、LEARN は自動で終わります

- 割り当ては保存されるので、次に開いたときもそのまま使えます
- LEARN ボタンを**右クリック**すると、その割り当てが無効（Off）に
  なります
- 画面の「CC 1」のような表示が、今の割り当てです

### 注意

MIDI をエフェクトに送る設定は DAW 側にも必要です。

- **Cakewalk Sonar** では、エフェクトの MIDI 入力を有効にしてください
- **YM ORPHEUS** はまだエフェクトへの MIDI 送信に未対応です
  （対応は別途予定）。ORPHEUS の中では今のところ CC 操作は使えません
