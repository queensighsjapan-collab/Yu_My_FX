# YM Orbit — 3D 空間パンナー VST3（v3 / 1.2.0）

音を「頭の周りの空間」に置くための VST3 エフェクトプラグインです。
Roland RSS や Auburn Sounds Panagement と同じ系統の発想
—— EQ（周波数特性）と位相／遅延を操作して、ステレオ 2ch のまま
音像を前後・左右・上下・遠近に動かす「スペクトラル／バイノーラル式」
パンナーです。自作コードのみで実装しています。

Cakewalk Sonar、YM ORPHEUS など、一般の VST3 ホストで使えます。

## 仕組み（正直な注記つき）

入力はまず「点音源」として扱います。ステレオ入力の中身（Mid＝モノラル和）を
バイノーラル・レンダリングし、元のステレオ感（Side＝左右差）は WIDTH で
戻せるようにしてあります。各ブロックで以下を適用します（全パラメーターに
約 45 ms のスムージング付き、フィルター係数はブロックごとに再計算）。

| 段 | 内容 | 近似について |
|---|---|---|
| 距離 | ゲイン `(1 / (1 + 距離m))^1.3` カーブ（8 m で約 −24 dB）＋空気吸収ローパス（近い 18 kHz → 遠い約 2.2 kHz） | 逆二乗則の簡易版です。距離は 0.3–8 m にマッピング |
| 上下 | ピーキングフィルターが 6 kHz（低）→ 10 kHz（高）と移動、上げ +6 dB／下げ −4.5 dB まで | ピンナ（耳介）キューの大幅な単純化です。個人差が大きく、効きには個体差があります |
| 左右・遅延 | ITD: 遠い耳だけに最大 1.1 ms の分数遅延（sin(方位)、上下で微減） | 頭部を球とみなした近似です。物理値（約 0.7 ms）より意図的に大きくしてあります |
| 左右・EQ | 頭部シャドウ: 遠い耳にハイシェルフ −16 dB（3 kHz 以上、sin(方位) で可変）＋全体 −16 dB まで低下。近い耳は +3 dB のプレゼンス | 実 HRTF の周波数応答はもっと複雑です |
| 部屋 | 自作 Schroeder リバーブ（並列コーム×4＋直列オールパス×2 / ch、L/R は長さをずらして無相関化）。ルーム量は距離でも増える（wet = ROOM × (0.35 + 0.65×距離)） | 小さな部屋の「場所の感じ」付け用で、ホール再現ではありません |

**v2（1.1.0）の強化について**: v1 の実測が「方位 ±90° で左右差 9.07 dB」
「距離最大で 8 kHz の追加減衰 5.87 dB」だったのに対し、v2 は全キューを
意図的に誇張し、実測で **左右差 13.94 dB**／**追加減衰 9.85 dB** まで
強くしています。正確さではなく「効果がはっきり分かること」優先の調整です。

**v3（1.2.0）の強化について**: かいさんの「もっと効果が大きく出てもいい」
という要望でさらに誇張しました。実測で **左右差 17.83 dB** まで拡大
（遠い耳の全体レベルは当初案の −13 dB だと 14.8 dB 止まりだったため
−16 dB に引き上げ）。あわせて Circle の動きを根本から大きくしています
（下記 MOTION の項）。
| WIDTH | 元入力の左右差信号に同じ距離 EQ をかけ、最大で半々まで再注入 | WIDTH 0 = 純粋な点音源、1 = ドライと元ステレオ差が半々 |

方位（Azimuth）は sin/cos でスムージングしているので、±180° の
境目を最短距離で通過し、真後ろをまたぐ動きでも破綻しません。

**大事な前提**: 前後・上下の知覚は近似であり、ヘッドホンと個人の耳の形に
強く依存します。スピーカーでは主に左右＋遠近の効果になります。
本物の HRTF 測定データは使っていません（自作の近似のみ）。

## パラメーター

| パラメーター | 範囲 | 初期値 | 内容 |
|---|---|---|---|
| Azimuth | −180–180° | 0° | 方位。0 = 正面、+ = 右、±180 = 真後ろ |
| Elevation | −40–+60° | 0° | 高さ |
| Distance | 0.0–1.0（表示 0.3–8.0 m） | 0.25（約 2.2 m） | 距離 |
| Width | 0.0–1.0 | 0.0 | 元のステレオ差の戻し量 |
| Room | 0.0–1.0 | 0.25 | リバーブ量（距離でも自動で少し増えます） |
| Output | −24–+12 dB | 0 dB | 出力ゲイン |
| Motion Mode | Off / Circle / Wander | Off | 自動で音源を動かすモード（下記） |
| Motion Rate | 0.05–3.0 Hz | 0.20 Hz | 動きの速さ（Circle の回転速度の基準）。v3 で上限を 2.0 → 3.0 Hz に拡大 |
| Motion Depth | 0.0–1.0 | 0.7 | 動きの強さ。0 で完全に静止 |

### MOTION（自動ムーブメント）

音源が勝手に頭の周りを動きます。動きはホストの再生位置に同期せず、
プラグイン内部のサンプル数で進むフリーラン方式です。

- **Circle**: 一定速度でぐるぐる回転します（真後ろも通過）。回転の
  速さは RATE × DEPTH で決まります（DEPTH 0 では止まります）。
  **v3 の Circle は動きが段違いに大きい**のが特徴です。距離が
  「今いる方位」に連動して 1 回転に 1 回大きくうねります:
  **正面に来るとぐっと近く**（DEPTH 1 で距離 −0.38)、**真後ろでは
  ぐっと遠く**（同 +0.38）なり、横では中立です。高さも ±22° と
  大きく上下し、後ろを通過するときはさらに沈み込みます（最大 −8°）。
  実測では、正面通過時と後方通過時で音量差 **11.8 dB** を確認しました。
  （v2 の Circle は距離が 1 回転に 2 回小さく脈動するだけでした）
- **Wander**: ランダムな目標地点を次々に選び、なめらかに漂い続けます。
  DEPTH 1 では左右 ±180°（真後ろまで）・遠近 ±0.45・上下 ±25° の
  全範囲をふらふら動きます。前後・左右・遠近が不規則に変わるので、
  「ランダムにぐるぐる」が欲しい場合はこちらです。
- パッドには、自分で置いた位置（薄い点）と、MOTION で実際に動いている
  現在位置（明るい点＋リング）の両方が表示されます。

- ステレオ入出力。モノ入力は「中央の音源」として扱います（モノ→ステレオも可）
- テール長は 1.5 秒としてホストに報告
- 状態は APVTS 経由で保存/復元（ホストのプロジェクトに残ります）
- 画面中央のパッドをドラッグすると Azimuth と Distance が同時に動きます

## ビルド（Windows）

前提: Visual Studio 2022 / 2026（「C++によるデスクトップ開発」ワークロード）と Git。

一番簡単なのは `build.bat` をダブルクリックする方法です（YM Echo / YM ORPHEUS と同じ方式）。
Visual Studio の検出、環境設定、CMake 構成、ビルドまで自動で行い、
ログは `build-log.txt` に残ります。初回は JUCE のダウンロードが入ります。

手動の場合:

```
cmake -B build -G "Visual Studio 17 2022" -A x64 -T v143
cmake --build build --config Release
```

（VS 2026 の場合はジェネレーター `"Visual Studio 18 2026"` / ツールセット `v145`）

成果物:

```
build\YMOrbit_artefacts\Release\VST3\YM Orbit.vst3
```

`YM Orbit.vst3` はファイルではなくフォルダーです。フォルダーごと
`C:\Program Files\Common Files\VST3` へコピーしてください（管理者権限の確認が出ます）。

**旧バージョンからの更新の場合**: プラグイン名もコード（Yorb）も同一なので、
`C:\Program Files\Common Files\VST3` にある古い `YM Orbit.vst3` フォルダーを
新しいビルドのものに**置き換えるだけ**で OK です。以前のバージョンで保存した
プロジェクトやプリセットの状態はそのまま読み込めます
（MOTION パラメーターは v1 で保存した状態では初期値で入ります。
v3 は Motion Rate の範囲を広げましたが、保存済みの値もそのまま使えます）。

## 聞き比べチェックリスト（かいさん向け）

ヘッドホン推奨です。モノラルに近い素材（ボーカル、シンセリード等）で試すと分かりやすいです。

1. **左右**: Azimuth を ±90° に振って、音がその側の耳に寄るか。真ん中（0°）に戻すと中央に戻るか
2. **真後ろ**: Azimuth 180° で「後ろっぽさ」が出るか（出方は耳の形で大きく変わります。出なくても故障ではありません）
3. **上下**: Elevation を上げ下げして、音像の高さ感が変わるか（これも個人差大。変わって聞こえる方向が逆の人もいます）
4. **遠近**: Distance を最大にして、音が小さく・こもって・部屋の響きが相対的に増えるか。最小で近く乾いた音に戻るか
5. **Width**: ステレオ素材で Width を上げると元の広がりが戻るか
6. **Pad**: パッドのドラッグで音が滑らかに付いてくるか（ジッパーノイズがないか）
7. **Room**: Room 0 で完全にドライになるか、上げると小さな部屋の響きが付くか
8. **強さ（v3）**: v2 よりさらに左右の寄りが大げさになったか（実測 13.94 → 17.83 dB）
9. **MOTION Circle**: Mode = Circle、RATE 0.2 Hz 前後、DEPTH 最大で、音が頭の周りを一周するか。パッドのリング付きドットが音に付いて回るか
10. **Circle の遠近（v3）**: Circle 中、正面に来たとき音が「ぐっと近く・大きく」、真後ろでは「遠く・小さく」なるか。前後の音量差がはっきり感じられるか。後ろを通過するとき少し沈む感じがするか
11. **高速回転（v3）**: RATE を 2 Hz 以上に上げて、速いぐるぐるが破綻なく回るか
12. **MOTION Wander**: Mode = Wander で、音が不規則に前後・左右・遠近をさまようか。DEPTH を下げると動きが大人しくなるか
