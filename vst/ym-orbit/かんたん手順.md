# YM Orbit かんたん手順（v3 / 1.2.0）

音を頭の周りの空間に置ける、3D パンナーのプラグインです。
作り方は YM Echo と同じ要領です。

v3 の変更点は 2 つです。

- **効果がさらに強くなりました**（左右の寄りが v2 よりもっと大げさに。
  実測で左右差 13.9 dB → 17.8 dB）
- **MOTION の Circle が大げさに動くようになりました**。
  回っている音が、正面に来ると「ぐっと近く」、真後ろでは「ぐっと遠く」
  なります。高さの上下も大きくなり、後ろを通るときは少し沈みます。
  ついでに RATE の上限が 3 Hz まで上がって、速く回せるようになりました

## 1. ビルドする

フォルダーの中の **build.bat** をダブルクリックしてください。

- 黒い画面が出て、自動で進みます
- 初回だけ部品（JUCE）のダウンロードで数分かかります
- 最後に **DONE!** と出たら成功です

途中で [ERROR] が出て止まったら、同じフォルダーにできる
**build-log.txt** をマネージャーに送ってください。

## 2. プラグインを所定の場所に置く

ビルドが終わると、フォルダーの中に

```
build → YMOrbit_artefacts → Release → VST3 → YM Orbit.vst3
```

という**フォルダー**ができています（ファイルじゃなくてフォルダーです）。

この **YM Orbit.vst3 フォルダーごと**、下の場所にコピーしてください。

```
C:\Program Files\Common Files\VST3
```

※ コピーのとき管理者権限の確認画面が出ます。「続行」でOKです。
※ **前のバージョンを入れていた場合**は、同じ場所にある古い
　 YM Orbit.vst3 フォルダーを新しいものに置き換えるだけです。
　 前のプロジェクトはそのまま開けます。

## 3. DAW で試す

1. YM ORPHEUS（または Cakewalk Sonar）を起動
2. 初回は **Scan for Plugins...** を実行
3. トラックの FX に **YM Orbit** を追加
4. **ヘッドホンで** 聞きながら試してください
   - **真ん中のパッド**をドラッグ = 音の位置（角度と距離）
   - **ELEVATION** = 高さ、**ROOM** = 部屋の響き、**WIDTH** = 元のステレオ感の戻し量
   - 前後・上下の感じ方は耳の形で変わります（近似の仕組みです）

## MOTION の使い方

画面の下に **MOTION** の欄があります。

- **モードのプルダウン**
  - **Off** … 動きません（今まで通り）
  - **Circle** … 一定の速さでぐるぐる回ります。
    **v3 では正面で近く・真後ろで遠く**なるので、回転に遠近の
    ドラマが付きます。まずはこれで遊んでみてください
  - **Wander** … ランダムに前後・左右・遠近をさまよい続けます。
    「ランダムにぐるぐる」はこちらがおすすめです
- **RATE** … 動きの速さ。まずは 0.2 Hz くらいが分かりやすいです
  （v3 で最大 3 Hz まで速くできます）
- **DEPTH** … 動きの強さ。最大でフルに動き回り、0 で止まります

MOTION が動いている間、パッドには **リング付きの明るい点** が
「今この瞬間の音の位置」として表示されます（薄い点は元の位置です）。

詳しい聞き比べポイントは README.md の「聞き比べチェックリスト」にあります。
