# YM Orbit（Mac版）テストのお願い

## YM Orbit って何？

音を頭のまわりにぐるぐる動かせる「3Dパンナー」エフェクト（VST3プラグイン）です。
左右・前後・遠近・上下に音の出どころを動かせます。**ヘッドホンで聴くのがおすすめ**です（スピーカーだと効果がかなり薄れます）。
Apple Silicon / Intel 両対応のユニバーサルバイナリです。

## インストール方法

1. zip を解凍して、**"YM Orbit.vst3"** を次のフォルダにコピーしてください
（管理者パスワードを求められます）

```
/Library/Audio/Plug-Ins/VST3/
```

※ ユーザーフォルダ配下の `~/Library/Audio/Plug-Ins/VST3/` でも大丈夫です。

2. **ターミナルで次のコマンドを1回実行してください。**
このプラグインは開発中のテスト版で、Appleの公証（ノータリゼーション）を受けていないため、この作業をしないとDAWに読み込まれません。

```
xattr -dr com.apple.quarantine "/Library/Audio/Plug-Ins/VST3/YM Orbit.vst3"
```

※ `~/Library/...` に入れた場合はこちらです：

```
xattr -dr com.apple.quarantine "$HOME/Library/Audio/Plug-Ins/VST3/YM Orbit.vst3"
```

3. DAWを再起動（またはプラグインの再スキャン）をして、適当なトラックに **"YM Orbit"** を挿してください。

## 聴いてみてほしいポイント

素材はボーカルやシンセパッドなど、持続音が分かりやすいです。

1. **静止状態**：AZIMUTH を左右いっぱいに振ると音が真横に寄るか。奥のDISTANCEを上げると遠く・こもった音になるか。
2. **MOTION = Circle**（画面下部）：RATE 0.2 Hzくらい、DEPTH 大きめで、音が頭の周りをぐるぐる回るか。前を通るとき近く・大きく、後ろでは遠くなるはずです。
3. **MOTION = Wander**：音がランダムにふらふら漂うか。
4. **ELEVATION**（右側の縦スライダー）：上下の感じが出るか。これは個人差が大きい部分なので、「なんとなく上っぽい」程度でも大丈夫です。

気づいたこと（鳴らない、画面が変、効果が弱い/強すぎる等）があれば、スクリーンショットや録音と一緒に教えてください。よろしくお願いします！
