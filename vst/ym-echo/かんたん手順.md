# YM Echo かんたん手順

これは、YM ORPHEUS で「プラグインがちゃんと動くか」を試すための、
小さなエコー（ディレイ）のプラグインです。作り方は ORPHEUS と同じ要領です。

## 1. ビルドする

フォルダーの中の **build.bat** をダブルクリックしてください。

- 黒い画面が出て、自動で進みます
- 初回だけ部品（JUCE）のダウンロードで数分かかります
- 最後に **DONE!** と出たら成功です

途中で [ERROR] が出て止まったら、同じフォルダーにできる
**build-log.txt** をマネージャーに送ってください。

## 2. プラグインを所定の場所に置く

ビルドが終わると、フォルダーの中に

```
build → YMEcho_artefacts → Release → VST3 → YM Echo.vst3
```

という**フォルダー**ができています（ファイルじゃなくてフォルダーです）。

この **YM Echo.vst3 フォルダーごと**、下の場所にコピーしてください。

```
C:\Program Files\Common Files\VST3
```

※ コピーのとき管理者権限の確認画面が出ます。「続行」でOKです。

## 3. YM ORPHEUS で試す

1. YM ORPHEUS を起動
2. **Scan for Plugins...** を実行（初回だけ）
3. トラックの FX に **YM Echo** を追加
4. 曲を再生して、エコーが聞こえたら成功です
   - **Time** = エコーの間隔、**Feedback** = 繰り返しの回数、**Mix** = エコーの大きさ
   - **Ping-Pong** をオンにすると、エコーが左右を行き来します

Cakewalk Sonar でも普通の VST3 エフェクトとして使えます。
