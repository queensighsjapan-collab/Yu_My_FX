# YM Amp 単体版 — インターフェイスなしで試す（v1.1.0）

オーディオインターフェイスが手元にない前提の、まず音を出すためのメモです。
入力は PC のマイク入力、出力は PC のヘッドフォン出力でそのまま使えます。
（遅延と音質の割り切りは下の「正直なところ」を参照してください。）

## 1. まず FILE モードで音出し確認（入力機器いらず）

ギターをつなぐ前に、アプリが鳴るかどうかだけ先に確かめられます。

1. `YM Amp.exe` を起動
2. 入力ソースを **FILE** に切り替え
3. **LOAD** で WAV などの音源（Stem など）を選ぶ
4. **PLAY** を押す

これでアンプチェーンを通った音が出れば、アプリ側は正常です。
ギター入力のトラブルと切り分けて考えられます。

## 2. ギターをマイク入力につなぐ

1. アプリのオーディオ設定（歯車／Audio Settings）で、入力に
   **マイク入力**、出力に **ヘッドフォン出力** を選ぶ
2. Windows のサウンド設定で、マイクの **「オーディオ拡張（エンハンス）」を
   オフ**にする（自動ゲインやノイズ抑制が演奏のダイナミクスと
   喧嘩するため）
3. マイク音量は、強く弾いても **歪まないところまで下げる**
4. 出力はヘッドフォンで（スピーカーだとハウリングしやすい）

## 3. 遅延を少しでも詰める

- 単体版の設定で **バッファを小さく**する
  （代わりに CPU 負荷は上がります。音が途切れるようなら戻す）
- それでも往復で数十 ms クラスの遅延は残ります。
  コード弾きやリフの確認なら遊べる範囲で、速いフレーズでは
  違和感が出ます

## 正直なところ

- ギターをマイク入力に直挿しするとインピーダンスが合わず、
  高域が落ちて少しこもった音になります
- だからこの構成は「試す・練習する」用です。
  本腰を入れるなら、ギター用 USB ケーブルか入門インターフェイスを
  足すと一気に化けます
- プリセットはまず **01 BRIT STACK**（初期状態）か、
  **02 EVH 5150**（◀ ▶ で切替）からどうぞ

同梱モデルのクレジットは README.md / CREDITS.txt を参照してください。
