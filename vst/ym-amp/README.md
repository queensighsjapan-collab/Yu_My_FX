# YM Amp — NAM プレイヤー VST3 / スタンドアロン（v1.1.0）

Neural Amp Modeler（NAM）のキャプチャデータ（`.nam` ファイル）を読み込んで
再生する、アンプシミュレーターです。プロファイリング（実機の取り込み）は
行わず、**再生専用**です。音作りの中核になるモデルは、無料の NAM
ライブラリ [TONE3000](https://www.tone3000.com/) などから入手した
`.nam` ファイルを **LOAD MODEL** ボタンで読み込んで使います
（A1 / A2 の両形式に対応。SlimmableContainer 形式も再生できます）。

Cakewalk Sonar、YM-Kithara など一般の VST3 ホストで使えます。

**単体版（Standalone）も同梱しています。** ビルドすると VST3 版と一緒に
`YM Amp.exe`（単体アプリ版）ができます。**単体版は DAW なしで起動でき**、
アプリのオーディオ設定からオーディオインターフェイスを直接選んで
そのままギターを弾けます。音の処理・画面・プリセットは VST3 版と
まったく同じで、違いは「DAW のトラックに挿すか、アプリ単体で動かすか」
だけです（DAW を持っていない人にもそのまま渡せます）。

## 信号の流れ

| 段 | 内容 |
|---|---|
| 入力ソース | **GUITAR**（ライブ入力）／ **FILE**（内蔵ステムプレイヤー）の切替。FILE は WAV / MP3 / FLAC / AIFF を読み込んで再生し、そのままアンプに通せます（Suno ステムのリアンプ用） |
| INPUT | 入力ゲイン ±24 dB |
| GATE | ノイズゲート（しきい値 −80〜−10 dB） |
| BOOST | トレブルブースター風（高域シェルフ＋メイクアップゲイン）。ON/OFF＋AMOUNT |
| NAM | `.nam` モデルの再生（NeuralAmpModelerCore、MIT）。48 kHz 学習のモデルは、ホストが別レートのとき自動でリサンプルして挟むので、44.1 kHz 等でも正しく鳴ります |
| 音量正規化 | モデルに loudness メタデータがある場合、基準 −18 dB に自動で揃えます（モデルごとの音量差を吸収） |
| CAB | キャビネット IR のコンボリューション。内蔵 IR（自作合成「YM CAB 4x12」）＋ユーザー WAV 読込、ON/OFF 可。フルリグ（キャブ込み）キャプチャを使うときは OFF に |
| EQ | BASS（150 Hz シェルフ）／ MID（750 Hz ピーク）／ TREBLE（3.2 kHz シェルフ）／ PRESENCE（5.5 kHz シェルフ）、各 ±15 dB |
| GAIN | モデル前段のドライブ（−12〜+24 dB）。画面の TONE 段にありますが、効く場所はモデルの前です |
| CHORUS | レート／深さ、ON/OFF |
| DELAY | タイム（30–1000 ms）／フィードバック／ミックス、ON/OFF |
| REVERB | アルゴリズミック・リバーブ、ミックス、ON/OFF |
| MASTER | 出力ゲイン −24〜+12 dB |

モデル未読込でも信号は素通りして EQ / FX は効きます（BOOST＋EQ だけの
プリアンプ風にもなります）。

## 同梱モデルとクレジット

工場プリセット用に、**再配布が明示的に許可された CC BY の
キャプチャを 2 つ同梱**しています。初回起動時にユーザー
フォルダー（`YM Amp\Factory`）へ自動で展開されます。

- **"EVH 5150 III 6L6 (Amp Only). Moderate Boost." by braindeadtx**
  Source: https://www.tone3000.com/tones/evh-5150-iii-6l6-amp-only-moderate-boost-205
  — licensed under CC BY 4.0
- **"1968 KT66 Marshall Plexi style amp v2.0" by ezlemoen**
  Source: https://www.tone3000.com/tones/1968-kt66-marshall-plexi-style-amp-v20-6806
  — licensed under CC BY 4.0

詳細は同梱の **CREDITS.txt** を見てください。内蔵キャビ IR は
第三者の IR ではなく、本プロジェクトで合成したものです。
ユーザー IR は自動ノーマライズなし（ファイルの録音レベルそのまま）で
使います。音量差は MASTER で調整してください。

※ VOX AC30 系（ブライアン・メイ風）や Roland JC-120 系のキャプチャは、
再配布可能なライセンスのものが見つからなかったため同梱していません。
TONE3000 からご自身でダウンロードした `.nam` は、個人利用として
そのまま読み込んで使えます。

## 工場プリセット

画面の ◀ ▶ で切り替えます（設定＋モデル参照のセットです）。

| # | 名前 | 内容 |
|---|---|---|
| 01 | BRIT STACK | 同梱プリキ（ezlemoen）＋中庸な EQ。電源 ON の初期状態 |
| 02 | EVH 5150 | 同梱 5150 III（braindeadtx）＋タイトなゲート、薄くディレイ／リバーブ |
| 03 | MAY CHIME | モデルは同梱なし（AC30 系モデルの読込を画面が案内）。BOOST ON でトレブルブースターを前方に |
| 04 | CLEAN CHORUS | モデルは同梱なし（JC 系クリーンモデル推奨）。CHORUS ON のクリーン設定 |

**SAVE** ボタンで現在の状態をユーザープリセットとして保存でき、
◀ ▶ の工場プリセットの後ろに追加されます
（保存先は `YM Amp\Presets` フォルダーの XML ファイル）。

| Input Source | GUITAR / FILE | GUITAR |

| Chorus Rate / Depth | 0.1–8 Hz / 0–1 | 1.2 Hz / 0.35 |

| Bypass CC | 0–127 | 65 |

## MIDI CC コントロール

YM の家訓どおり、ON/OFF（バイパス）を MIDI CC で操作できます。

- **Bypass CC（初期 CC 65）**：値 64 以上でエフェクト ON、未満で
  バイパス。切替は約 15 ms のクロスフェードでクリックなし。
  ホストのバイパスボタンとも連動します
- 画面下の **LEARN** を押してからコントローラーを動かすと、その
  CC 番号に割り当て直せます。LEARN の**右クリック**で無効（Off）
- チャンネルは問いません（オムニ受信）

ホスト側でエフェクトへの MIDI ルーティングが必要です
（Sonar はエフェクトの MIDI 入力を有効化、等）。

## ビルドとインストール

1. フォルダー内の **build.bat** をダブルクリック（初回は JUCE の
   ダウンロードで数分かかります）
2. VST3 版：`build → YMAmp_artefacts → Release → VST3` の
   **YM Amp.vst3 フォルダーごと** を
   `C:\Program Files\Common Files\VST3` にコピー
3. 単体版：`build → YMAmp_artefacts → Release → Standalone` の
   **YM Amp.exe** を好きな場所に置いて実行（DAW 不要。
   初回はアプリのオーディオ設定で入出力デバイスを選んでください）
4. DAW 側でプラグインの再スキャンを実行

詳しい手順は同梱の「かんたん手順.md」を見てください。

## 正直な注記

- NAM は「キャプチャした瞬間の音」の再現です。アンプのツマミは
  再現できないので、「誰々っぽい音」の大半はモデル選びで決まり、
  残りを BOOST と EQ で詰める作りです
- 44.1 kHz 等のホストでは NAM の前後でリサンプルが入るため、
  数サンプル分のレイテンシーが増えます（ホストには申告します）
- 音の最終確認は Windows 実機での試聴が前提です
  （開発環境ではヘッドレスの数値検証のみ実施）

## 聴き方のチェックポイント

- EVH 5150 プリセット：ゲートの締まり具合（パームミュートで
  ノイズがスッと切れるか）、ディレイの薄がけ
- BRIT STACK プリセット：コードを弾いたときのプリキらしい
  張りと、GAIN を上げたときの歪みの追随
- FILE ソース：Suno のギターステムを読み込んで PLAY、
  ライブ入力と同じ音作りがそのままかかるか
- 単体版：デバイス設定でインターフェイスを選んで弾けるか
