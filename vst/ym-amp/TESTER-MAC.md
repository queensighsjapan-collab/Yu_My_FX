# YM Amp（Mac版）テストのお願い

## YM Amp って何？

NAM（Neural Amp Modeler）のキャプチャを読み込んで鳴らす、アンプシミュレーターです（VST3プラグイン＋単体アプリの2形態）。
ゲート → トレブルブースター → NAMモデル → キャビIR → EQ → コーラス／ディレイ／リバーブ、という一式が入っていて、WAVなどのファイルを再生してアンプに通す「ステムプレイヤー」も内蔵しています。
Apple Silicon / Intel 両対応のユニバーサルバイナリです。

同梱の工場プリセット（モデル入りですぐ鳴ります）：

- **EVH 5150**（EVH 5150 III のキャプチャ、CC BY: braindeadtx）
- **BRIT STACK**（1968 KT66 Plexi スタイルのキャプチャ、CC BY: ezlemoen）

MAY CHIME / CLEAN CHORUS は設定だけのプリセットで、モデルは LOAD MODEL から自分の .nam ファイルを選んでください。

## インストール方法（VST3）

1. zip を解凍して、**"YM Amp.vst3"** を次のフォルダにコピーしてください
（管理者パスワードを求められます）

```
/Library/Audio/Plug-Ins/VST3/
```

※ ユーザーフォルダ配下の `~/Library/Audio/Plug-Ins/VST3/` でも大丈夫です。

2. **ターミナルで次のコマンドを1回実行してください。**
このプラグインは開発中のテスト版で、Appleの公証（ノータリゼーション）を受けていないため、この作業をしないとDAWに読み込まれません。

```
xattr -dr com.apple.quarantine "/Library/Audio/Plug-Ins/VST3/YM Amp.vst3"
```

※ `~/Library/...` に入れた場合はこちらです：

```
xattr -dr com.apple.quarantine "$HOME/Library/Audio/Plug-Ins/VST3/YM Amp.vst3"
```

3. Ableton Live の場合：環境設定 → Plug-Ins で **VST3 の再スキャン（Rescan）** をして、トラックに **"YM Amp"** を挿してください。

## 単体アプリ（DAWなしで試す場合）

- **"YM Amp.app"** をそのままダブルクリックで起動できます（「アプリケーション」フォルダにコピーしてもOKです）。
- 初回起動で「開発元を確認できない」と出たら、右クリック →「開く」で開いてください。またはターミナルで：

```
xattr -dr com.apple.quarantine "/Applications/YM Amp.app"
```

（zip解凍直後の場所で使う場合は、そのパスに読み替えてください）

- 起動したら設定画面で入出力デバイス（マイク／オーディオインターフェイスと、出力先）を選んでください。ギターを直接つないでも、FILEプレイヤーで音源ファイルを鳴らすだけでも試せます。

## 試してみてほしいポイント

1. **読み込めるか**：DAWに VST3 が出てきて、画面が開くか。単体アプリも起動するか。
2. **工場プリセット**：◀ ▶ で **EVH 5150** と **BRIT STACK** を切り替えて、どちらも音が出るか（モデル名がアンバー色の表示窓に出ます）。
3. **FILEプレイヤー**：入力ソースを FILE にして、WAV（ステム等）を読み込み、再生ボタンでアンプを通した音が鳴るか。GUITAR に戻すと通常入力に戻るか。
4. **内蔵エフェクト**：DELAY の **FEEDBACK** つまみがあるか／効くか。CHORUS、REVERB、BOOST もON/OFFとつまみが効くか。
5. **バイパス**：左上の電源ボタン（または MIDI CC65）で、音が途切れずにON/OFFが切り替わるか。
6. **自分のモデル**：お手持ちの .nam ファイルがあれば LOAD MODEL から読み込めるか。

気づいたこと（鳴らない、画面が変、効果が弱い/強すぎる等）があれば、スクリーンショットや録音と一緒に教えてください。よろしくお願いします！
