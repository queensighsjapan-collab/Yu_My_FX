# YM Amp かんたん手順（v1.1.0）

NAM（Neural Amp Modeler）のキャプチャデータを再生する
アンプシミュレーターです。TONE3000 などで配られている
「.nam」ファイルを読み込むと、そのアンプの音が再現されます。
同梱モデルが 2 つ入っているので、最初から音は出ます。

## 1. ビルドする

フォルダーの中の **build.bat** をダブルクリックしてください。

- 黒い画面が出て、自動で進みます
- 初回だけ部品（JUCE）のダウンロードで数分かかります
- 最後に **DONE!** と出たら成功です

途中で [ERROR] が出て止まったら、同じフォルダーにできる
**build-log.txt** をマネージャーに送ってください。

## 2. 置き場所

### VST3 版（DAW で使う）

```
build → YMAmp_artefacts → Release → VST3 → YM Amp.vst3
```

この**フォルダーごと**、下の場所にコピーしてください。

```
C:\Program Files\Common Files\VST3
```

### 単体版（DAW なしで使う）

```
build → YMAmp_artefacts → Release → Standalone → YM Amp.exe
```

この **YM Amp.exe** を実行するだけです。DAW は要りません。
初回は画面のオプション（歯車／Audio Settings）から
オーディオインターフェイスの入出力を選んでください。
DAW を持っていないギター仲間に渡すときは、この exe だけで OK です
（相手の PC にビルド環境は要りません）。

## 3. DAW で試す（VST3 版）

1. YM-Kithara（または Cakewalk Sonar）を起動
2. 初回は **Scan for Plugins...** を実行
3. トラックの FX に **YM Amp** を挿す

## 4. 使い方

### まずプリセットで鳴らす

- 画面の **PRESET 01 — BRIT STACK** が初期状態です
  （同梱のプリキ風モデルが読み込み済み）
- **◀ ▶** で **02 EVH 5150** に切り替えると、同梱の 5150 III
  モデル＋タイトなゲート＋薄いディレイの音になります

### 自分のモデルを読み込む

1. TONE3000（https://www.tone3000.com/）で好きなアンプの
   NAM キャプチャをダウンロード
2. **LOAD MODEL** ボタンでその `.nam` ファイルを選ぶ
3. キャブ込み（Full Rig）のキャプチャなら **CAB** を OFF、
   アンプのみのキャプチャなら CAB ON のまま内蔵キャビや
   **LOAD IR** で読み込んだ IR と組み合わせます

### Stem をリアンプする（FILE 入力）

1. 入力ソースを **FILE** に切り替える
2. ファイル表示の下の **LOAD** で Stem（WAV / MP3 / FLAC）を選ぶ
3. **PLAY** を押すと、その音がアンプチェーンを通って鳴ります
   （LOOP を点けておくと繰り返し再生）

### 音作りのコツ

- **GAIN** はモデルの前段ドライブです。モデルの歪み量は
  まずここで調整
- ハイゲインでノイズが気になるときは **GATE** を上げる
  （−38 dB くらいでかなりタイトになります）
- ブライアン・メイ風は **MAY CHIME** プリセット＋
  AC30 系モデル（各自でダウンロード）を読み込んで **BOOST** ON
- ジャズコーラス風は **CLEAN CHORUS** プリセット＋
  クリーンなモデルで **CHORUS** を効かせます

## つまみの意味（英語表示のまま）

| 表示 | 意味 |
|---|---|
| INPUT | 入力レベル |
| GAIN | モデル前段のドライブ（歪み量） |
| BASS / MID / TREBLE | 3 バンド EQ |
| PRESENCE | 高域の張り |
| GATE | ノイズゲートのしきい値 |
| MASTER | 最終音量 |
| BOOST | トレブルブースター（AMOUNT が量） |
| CHORUS | RATE = 速さ、DEPTH = 深さ |
| DELAY | TIME = 間隔、MIX = 混ぜ具合 |
| REVERB | MIX = 混ぜ具合 |
| CAB | キャビネット IR の入／切 |

## 5. MIDI コントローラーで ON/OFF する

ON/OFF（バイパス）は最初から **CC 65** に割り当てられています
（値が大きいと ON、小さいとバイパス）。

### 割り当てを変えたいとき（MIDI ラーン）

1. 画面下の **LEARN** ボタンを押します（ボタンが光ります）
2. 使いたいコントローラーのツマミやペダルを動かします
3. その番号が割り当てられて、LEARN は自動で終わります

- LEARN ボタンを**右クリック**すると割り当てが無効になります
- 画面左下の POWER スイッチ（手動の ON/OFF）でも切り替えられます

### 注意

MIDI をエフェクトに送る設定は DAW 側にも必要です。
Cakewalk Sonar では、エフェクトの MIDI 入力を有効にしてください。
