はじめに

YM Amp（ワイエム・アンプ）は、Neural Amp Modeler（NAM）のキャプチャデータ（.nam ファイル）を読み込んで再生する、再生専用のアンプシミュレーターです。実機アンプを手元で取り込む（プロファイリング）機能はありません。その代わり、無料の NAM ライブラリ TONE3000 などで配布されているキャプチャを読み込むと、そのアンプの音がそのまま再現されます。対応形式は NAM の A1 / A2 の両形式（SlimmableContainer 形式も再生できます）。

再配布が許可されたモデルが2つ同梱されているので、最初から音は出ます。起動すると初期プリセット「01 BRIT STACK」が選ばれ、同梱のプリキ風モデルが読み込まれた状態になっています。パネル（画面）の表記はすべて英語です。画面サイズは固定（1240×430）で、大きさは変わりません。

VST3版と単体版の違い

YM Amp には2つの形がありますが、中身（音の処理・画面・プリセット）はまったく同じです。違うのは「誰がオーディオ機器を管理するか」と「状態の保存先」だけです。

項目VST3版単体版（YM Amp.exe）
使い方DAW（YM-Kithara、Cakewalk Sonar など）のトラックに挿して使うアプリ単独で起動する。DAWは要らない
入出力デバイスホスト（DAW）側の設定に従うアプリのオーディオ設定で、自分で入力・出力・バッファサイズを選ぶ
状態の保存先ホストのプロジェクトファイルに一緒に保存されるアプリ自身が終了時の状態を覚えていて、次回起動時に復元する
向いている用途録音、他のプラグインとの併用、ステムへの一括処理手軽にギターを鳴らす、DAWを持っていない人への配布

インストール

  1. VST3版：YM Amp.vst3 のフォルダーごと、C:\Program Files\Common Files\VST3 にコピーします（中身だけを取り出さないでください）。DAW を起動し直すか、プラグインの再スキャンを実行します。
  2. 単体版：YM Amp.exe を好きな場所に置いて実行するだけです。初回起動時は、画面のオプション（歯車／Audio Settings）から使いたいオーディオインターフェース（またはPCのマイク入力／ヘッドホン出力）を選んでください。

メモ：初回起動時に、同梱モデルはユーザーフォルダーの YM Amp\Factory へ自動で展開されます。自分で保存したプリセットは YM Amp\Presets フォルダーに XML ファイルとして置かれます。

信号の流れ

音は下の順番で処理されます。アンプ本体にあたるのは NAM モデルで、それ以外は「アンプの前段・後段」として働きます。

段内容
入力（GUITAR / FILE）GUITAR＝ライブ入力、FILE＝内蔵ファイルプレイヤー。どちらもモノラルにまとめられてアンプ段へ入ります
INPUT（入力ゲイン）チェーン先頭のレベル調整（±24 dB）
GATEノイズゲート。しきい値より小さい音を消します
BOOSTトレブルブースター（モデル前段）。詳しくは「内蔵エフェクター」
GAINモデル前段のドライブ。パネルでは TONE 段に並んでいますが、効く場所はモデルの前です。モデルの歪み量はまずここで調整します
NAM モデル.nam キャプチャの再生。モデルに音量（loudness）情報がある場合は、基準 −18 dB に自動で揃えてモデル間の音量差を吸収します
CAB（キャビ IR）キャビネットのインパルス応答（IR）で「箱鳴り」を付けます
EQ / PRESENCEBASS / MID / TREBLE / PRESENCE の4バンドで最終的な音色を整えます
CHORUS → DELAY → REVERB空間系の内蔵エフェクター（アンプの後段、いわゆるエフェクトループ的な位置）
MASTER最終出力レベル（−24〜+12 dB）

メモ：モデルを何も読み込んでいなくても信号は素通りし、EQ とエフェクターは効きます（BOOST＋EQ だけのプリアンプ風の使い方もできます）。

基本の使い方

モデル（.nam）を読み込む

  1. TONE3000 などで好きなアンプの NAM キャプチャ（.nam ファイル）をダウンロードします。
  2. パネルの LOAD MODEL を押し、ファイル選びます。
  3. 読み込まれると、アンバー色の LCD にモデル名と、その下に形式（例：WAVENET - 48 kHz）が表示されます。何も読み込まれていないときは NO MODEL LOADED と表示されます。

プリセット（◀ ▶）

プリセット表示の横の ◀ ▶ で切り替えます。プリセットは「設定＋モデル参照」のセットです。工場プリセットは4つあります。

#名前内容と用途
01BRIT STACK同梱の「1968 KT66 Marshall Plexi style amp v2.0」（ezlemoen）を読み込んだ、マーシャル系の基本音。GAIN +8 dB、ゲート −55 dB、薄くリバーブ。起動時の初期状態です
02EVH 5150同梱の「EVH 5150 III 6L6 (Amp Only). Moderate Boost.」（braindeadtx）＋タイトなゲート（−38 dB）＋薄いディレイ（320 ms）とリバーブ。ハイゲインのリフ向け
03MAY CHIMEブライアン・メイ風の作り（BOOST ON、AMOUNT 0.8）ですが、AC30系モデルは同梱されていません（理由は「同梱モデルとライセンス」）。LCD が LOAD AN AC30-STYLE MODEL と案内するので、各自で入手した AC30 系モデルを LOAD MODEL で読み込んでください（それまでは今のモデルがそのまま残ります）
04CLEAN CHORUSジャズコーラス風のクリーン＋コーラス（CHORUS ON）。こちらも JC 系モデルは同梱されていないので、クリーンなモデルを読み込むのがおすすめです（LCD に LOAD A CLEAN JC-STYLE MODEL と出ます）
  • SAVE を押すと、現在の状態を名前を付けてユーザープリセットとして保存できます。保存したプリセットは、工場プリセットの後ろに ◀ ▶ の巡回に追加されます。

内蔵ファイルプレイヤー（Stem のリアンプ）

ギター入力の代わりに、音声ファイルをそのままアンプチェーンに通せます。Suno などで作ったギターステムを「リアンプ」する用途です。

  1. 入力ソースの FILE を押します（GUITAR がライブ入力側です）。
  2. ファイル表示の下の LOAD でファイル選びます。対応形式は WAV / MP3 / FLAC / AIF / AIFF（読み込みは最大15分まで）。
  3. PLAY で再生、もう一度押すと STOP になります。最後まで再生し終わった後に PLAY を押すと、先頭から再生し直します。
  4. LOOP を点けておくと、終わりで先頭に戻って繰り返し再生します。

ヒント：ステムは既に音作り（歪みや空間処理）が済んでいることが多いので、アンプに通すと「二重に加工された」音に聞こえる場合があります。音の良し悪しの最終判断は、できればドライなギター素材か実際のギター入力でどうぞ。

キャビ IR を読み込む（LOAD IR）と CAB の ON/OFF

  1. LOAD IR を押して、キャビネット IR の WAV ファイル選びます（標準では内蔵 IR「YM CAB 4x12」が使われます）。選んだ IR 名は LCD に表示されます。
  2. CAB ON / CAB OFF ボタンで、キャビ IR の有効・無効を切り替えます。

注意：読み込んだモデルがキャブ込みのキャプチャ（Full Rig）のときは、CAB OFF にしてください。キャビが二重に掛かると、こもった不自然な音になります。逆にアンプのみのキャプチャでは CAB を ON にして、内蔵 IR や読み込んだ IR と組み合わせます。

  • ユーザー IR は自動で音量を揃える処理をしません（ファイルの録音レベルそのまま）。音量差は MASTER で調整してください。

内蔵エフェクター

エフェクトは4つ内蔵しています。各ブロックの名前ボタン（LED 付き）で ON/OFF、ツマミで量を調整します。設定はプリセットにも保存されます。フェイザーのような凝ったエフェクトは、YM Vortex など他の YM エフェクトを後段に挿して使う想定です。

BOOST ― トレブルブースター

モデル前段に掛かるブースターです。高域（1.8 kHz のハイシェルフ、最大 +12 dB）を持ち上げながら、全体も最大 +10 dB 押し上げてモデルを強くドライブします。VOX AC30 系のモデルと組み合わせると、ブライアン・メイ風の「粘るサステイン」の土台になります（MAY CHIME プリセットがこの使い方です）。AMOUNT は1つのツマミで両方が連動します。

CHORUS

遅延変調によるコーラスです。RATE でうねりの速さ、DEPTH で深さを調整します。ジャズコーラス系のクリーンサウンドには欠かせない要素で、CLEAN CHORUS プリセットでは ON になっています（RATE 1.4 Hz / DEPTH 0.45）。

DELAY

ステレオのフィードバック・ディレイです。TIME（30–1000 ms）で間隔、FEEDBACK（0–0.85）で反響の繰り返し回数、MIX で混ぜ具合を調整します。EVH 5150 プリセットでは 320 ms の薄いディレイが空間作りに使われています。

REVERB

アルゴリズミック・リバーブ（Freeverb 系）です。部屋鳴りを薄く足すことで、アンプシミュレーター特有の「ペラペラ感」を消します。調整は MIX のみで、部屋の大きさなどは固定です。

MIDI

YM の家訓どおり、エフェクトの ON/OFF（バイパス）は MIDI CC で操作できます。

  • BYPASS CC（初期値 CC 65）：値が 64 以上でエフェクト ON、64 未満でバイパス（ペダル式）です。切り替えは約15 ms のクロスフェードで、クリック音はしません。
  • 画面左下の POWER スイッチ（手動の ON/OFF）およびホストのバイパスボタンとも連動します。
  • 割り当ての変更（LEARN）：画面下の LEARN を押してからコントローラーを動かすと、その CC 番号に割り当て直されます（LEARN は自動で終わります）。
  • LEARN を右クリックすると割り当てが無効（Off）になります（BYPASS CC = 0）。
  • MIDI はチャンネルを問わず受け付けます（オムニ受信）。

メモ：VST3版で CC を使うには、ホスト側で「エフェクトへ MIDI を送る」設定が必要です。Cakewalk Sonar ではエフェクトの MIDI 入力を有効にしてください。YM-Kithara ではトラックの M→FX を有効にします。単体版では、アプリのオーディオ／MIDI設定で使う MIDI 入力デバイスを選んでください。

同梱モデルとライセンス

工場プリセット用に、再配布が明示的に許可された CC BY 4.0 のキャプチャを2つ同梱しています（初回起動時に YM Amp\Factory フォルダーへ自動展開されます）。作者クレジットは以下の通りです（同梱の CREDITS.txt にも同じ内容が記載されています）。

モデル作者と出典
EVH 5150 III 6L6 (Amp Only). Moderate Boost.by braindeadtx ― TONE3000 の配布ページ／ CC BY 4.0
1968 KT66 Marshall Plexi style amp v2.0by ezlemoen ― TONE3000 の配布ページ／ CC BY 4.0
  • 内蔵キャビ IR「YM CAB 4x12」は、第三者の IR ではなく本プロジェクトで合成したものです。
  • モデルの再生エンジンは NeuralAmpModelerCore（MIT ライセンス）です。本体は JUCE で作られています。
  • VOX AC30 系（ブライアン・メイ風）や Roland JC-120 系のキャプチャは、再配布可能なライセンスのものが見つからなかったため、同梱していません。

注意：TONE3000 から自分でダウンロードしたモデルは、個人で使う分には問題ありません（YM Amp に読み込んで演奏・録音に使えます）。ただし、TONE3000 のモデルの多くは「使うのは自由でも、データファイルの再配布は作者の許可が必要」というライセンス（T3K）です。他人のモデルファイルを他人に渡したり、別の製品に同梱したりしないでください。YM Amp に同梱できている2つは、再配布を明示的に許可した CC BY のものだけです。

音が出ない・遅延が大きいとき

音が出ない（単体版）
まずアプリのオーディオ設定（オプション／Audio Settings）で、入力と出力のデバイスが正しく選ばれているか確認してください。入力にオーディオインターフェース（またはPCのマイク入力）、出力にヘッドホンなどを選びます。デバイスを選んだだけでは鳴らず、YM Amp 側の POWER が ON（バイパスされていない）ことも確認してください。
音が出ない・途切れて聞こえる（共通）
次の順で確認してください。①入力ソース（GUITAR / FILE）が今の使い方と合っているか。② GATE を上げすぎると、小さい音が全部消えて「音が出ない」ように聞こえます（初期値 −50 dB に戻してみてください）。③ INPUT と MASTER が下がりすぎていないか。④ VST3版では、ホスト側のトラック入力・モニター設定も確認してください。
FILE（ステム）が再生されない
ファイル形式が WAV / MP3 / FLAC / AIF / AIFF のいずれか確認してください（読み込み上限は15分です）。LOAD で読み込んでから PLAY を押します。入力ソースが FILE 側になっていないと、再生しても音は出ません。
音がこもる・不自然に重い
モデルがキャブ込み（Full Rig）のキャプチャなのに CAB が ON になっていて、キャビが二重に掛かっている可能性が高いです。CAB OFF にしてみてください。逆にアンプのみのキャプチャで CAB が OFF だと、耳障りな「生」の音になります。
遅延（レイテンシー）が大きい
バッファサイズを小さくすると遅延は減りますが、その分 CPU の負担が増え、音が途切れる場合があります（単体版はアプリのオーディオ設定、VST3版はホストの設定で変更します）。なお、NAM のモデルは 48 kHz を基準に作られているため、ホストが 44.1 kHz などのときはプラグインの内部で自動リサンプルします。このとき数サンプル分の遅延が増えますが、ホストへ申告しているので、並んだトラックとのズレはホスト側で補正されます。
PCのマイク入力にギターをつないだら音がこもる
これは故障ではなく、インピーダンス（電気的な相性）の違いによるものです。マイク入力はマイク用に設計されているため、ギターを直挿しすると高域が落ちてこもった音になります。また、Windows のマイクの「オーディオ拡張（エンハンス）」や自動ゲイン（AGC）が効いていると、演奏の強弱に音量が勝手に追従して不自然になります。サウンド設定でマイクの拡張機能を切り、入力レベルは音が割れない（クリップしない）範囲で調整してください。本来の使い方としては、Hi-Z（楽器用）入力のあるオーディオインターフェース経由が正解です。マイク入力でも「使えなくはない」範囲では鳴りますが、音質と遅延の両面でインターフェースが勝ります。

動作環境

  • 対応OS：Windows（64bit）
  • VST3版：VST3（64bit）対応ホスト（YM-Kithara、Cakewalk Sonar など）
  • 単体版：YM Amp.exe 単体で動作（DAW不要）。入出力には Windows で使えるオーディオデバイスが必要です
  • 対応ファイル形式：モデル＝ .nam（NAM A1 / A2、SlimmableContainer 含む）／ キャビ IR ＝ WAV ／ ファイルプレイヤー ＝ WAV・MP3・FLAC・AIF・AIFF（最大15分）
  • 開発フレームワーク：JUCE（モデル再生エンジン：NeuralAmpModelerCore、MIT）

メモ：NAM は「キャプチャした瞬間の音」の再現です。実機のアンプのツマミを後から回すことはできないので、「誰々っぽい音」の大半はモデル選びで決まり、残りを BOOST と EQ で詰める作りになっています。
