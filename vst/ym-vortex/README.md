# YM Vortex — 多段フェイザー VST3（v1.1.0）

> **v1.1.0 の変更点**（v1.0.0 のセーブデータはそのまま読めます）
> - **FEEDBACK を ±0.85 → ±0.97 に拡大**。強くすると共振ピークが
>   笛のように唸ります。戻し経路に tanh のソフトクリップに加えて
>   約 25 Hz のハイパスを入れたので、低音のこもりが溜まらず、
>   0.97 でも暴走しません
> - **DEPTH の上の方を伸ばしました**。DEPTH 0.66 までの掃引幅は
>   v1.0 と同じ（±1.5 オクターブ × DEPTH）ですが、そこから滑らかに
>   伸びて DEPTH 100% で ±2 オクターブ。ノッチの移動量が最大で
>   8 倍 → **16 倍** になりました
> - 深いうねりのレシピ: STAGES 12 / DEPTH 90–100% /
>   FEEDBACK +80–95% / RATE ゆっくり（0.1–0.3 Hz）

1 次オールパスの段を縦に重ねた、多段フェイザーの VST3 エフェクトです。
段数 4 / 6 / 8 / 12 を切り替えられ、ノッチ（音がへこむ周波数）は
段数 ÷ 2 本現れます。最大の特徴は **2 本の LFO による掃引** です。
LFO2 が LFO1 と割り切れない速度比で走るため、うねりの模様が
単純に繰り返さず、時間とともに変化し続ける「複雑な渦」になります。
自作コードのみで実装しています。

Cakewalk Sonar、YM ORPHEUS など、一般の VST3 ホストで使えます。

## 仕組み

| 段 | 内容 |
|---|---|
| オールパス段 | 各段は 1 次オールパス（通過帯域は平坦、位相だけが回る素子）。中心周波数は CENTRE を幾何中心に **3 オクターブの幅で対数間隔** に配置。全段が掃引で一緒に動きます |
| 出力の作り | 原音 ＋ 位相の回った音 を混ぜると、位相が 180° ずれた周波数で打ち消し合ってノッチが生まれます（フェイザーの原理そのもの）。MIX は「原音だけ」と「この古典的な混合」の間のクロスフェードです |
| フィードバック | 「原音＋最終段」の混合点（＝フェイザーの出力そのもの）から、tanh のソフトクリップ（±2 まで余裕を持たせた形。素の tanh だとループ信号自体で飽和して共振が伸び止まるため）を通し、約 25 Hz のハイパスを通して初段に戻します。この戻し方だとノッチの深さが保たれたまま共振ピークだけが持ち上がります（最終段だけから戻すとノッチが浅くなってしまうため）。符号つきで、マイナス側はもうひとつの古典的な味わいになります。範囲は ±0.97（v1.1 で拡大）。ループのピークゲインは |fb| × 最大 1 倍という構造上 1 未満に収まるので、強くしても唸って飽和する止まりで、発振・暴走はしません。ハイパスは高フィードバック時に低音のこもりが何秒も回り続けるのを防ぐためです |
| LFO1 | RATE（0.02–8 Hz、対数）で回る主 LFO。波形は正弦波／三角波 |
| LFO2 | RATE × RATIO（0.25–4 倍）で回る副 LFO。正弦波。DEPTH 2 で混ざります |
| 掃引量 | 混合した変調 m は (1 + DEPTH2) で割って ±1 に正規化され、全段の周波数が 2^(±R × m) 倍されます。R（掃引の半幅）は DEPTH 0.66 まで 1.5 × DEPTH（v1.0 と同一）、そこから二次カーブで滑らかに伸びて DEPTH 1 で 2.0 オクターブ。段の周波数はサンプルレートの 0.45 倍で頭打ちにしています |
| ステレオ | 左右は独立した段チェーンを持ち、右側の LFO 位相だけが WIDTH 分ずれます（0° = 連動、90° = 直交ステレオ、180° = 逆向き掃引） |
| 係数更新 | オールパスの係数は 1 サンプルごとに再計算しているので、速い掃引でも段のチューニングが崩れません |

### デュアル LFO について

RATIO に 1.618（黄金比）のような割り切れない数を入れると、
LFO1 と LFO2 の合計波形は（実質的に）二度と同じ形に戻りません。
うねりが「また同じパターンか」と感じさせないのが狙いです。
逆に懐かしい一定周期のフェイザーが欲しいときは DEPTH 2 = 0 で
LFO1 だけの古典的な動きになります。

## MIDI バイパス（YM ハウス標準）

YM のエフェクトは今後すべてこの仕様で統一されます。

- パラメーター **Bypass** が本体で、これをホストのバイパスボタンにも
  連動させています（getBypassParameter で返しています）
- パラメーター **Bypass CC**（初期値 65、0 = 無効）に割り当てた CC で
  操作できます。**値 64 以上 = ON（効果あり）／ 64 未満 = OFF（バイパス）**
- エディター下部の **LEARN** を押してからコントローラーを動かすと、
  その CC 番号に付け替えられます。LEARN を右クリックすると無効（Off）
- バイパスは約 15 ms のクロスフェードで、完全にバイパス中は
  段チェーンを止めて原音がそのまま通ります（LFO だけは回り続け、
  復帰した瞬間も掃引の途中から再開します）

※ ホスト側で「エフェクトへ MIDI を送る」設定が必要です
（Sonar ではエフェクトの MIDI 入力を有効にしてください。
YM ORPHEUS では M3.3 以降、トラックの M→FX トグルで送れます）。

## パラメーター

| パラメーター | 範囲 | 初期値 | 内容 |
|---|---|---|---|
| Rate | 0.02–8 Hz（対数） | 0.3 Hz | LFO1 の速さ |
| Depth | 0–1 | 0.7 | LFO1 の掃引量（0.66 まで v1.0 と同じ、1 で ±2 オクターブ） |
| Ratio | 0.25–4（対数） | 1.618 | LFO2 の速度 = Rate × Ratio |
| Depth 2 | 0–1 | 0.3 | LFO2 の混合量 |
| Centre | 100–4000 Hz（対数） | 800 Hz | 段の配置の幾何中心 |
| Feedback | −0.97–+0.97 | 0.3 | 符号つきフィードバック（v1.1 で拡大） |
| Stages | 4 / 6 / 8 / 12 | 6 | オールパスの段数（ノッチは半分） |
| Width | 0–180° | 90° | 右 LFO の位相オフセット |
| Wave | Sine / Triangle | Sine | LFO1 の波形 |
| Mix | 0–1 | 0.5 | 原音 ↔ 古典的フェイザー混合 |
| Output | −24–+12 dB | 0 dB | 出力ゲイン |
| Bypass | on/off | off（有効） | MIDI 対応バイパス |
| Bypass CC | 0–127（0 = 無効） | 65 | バイパス用 CC |

## ビルドとインストール

1. フォルダー内の **build.bat** をダブルクリック（初回は JUCE の
   ダウンロードで数分かかります）
2. `build → YMVortex_artefacts → Release → VST3` にできる
   **YM Vortex.vst3 フォルダーごと** を
   `C:\Program Files\Common Files\VST3` にコピー
3. ホスト側でプラグインの再スキャンを実行

詳しい手順は同梱の「かんたん手順.md」を見てください。

## 聴き方のチェックポイント

- ギターやパッドに 6 段 / Rate 0.3 Hz / Depth 70% / Feedback 30%:
  懐かしいフェイザーのうねりになるか
- 12 段 / Ratio 1.62 / Depth 2 50%: うねりの模様が繰り返さず、
  ゆっくり表情を変え続けるか（数分聴いてみてください）
- Width 0° ↔ 180° で、モノラル連動 ↔ 左右が逆向きにうねる
  ステレオ感に変わるか
- 12 段 / Depth 90–100% / Feedback +80–95% / Rate 0.1–0.3 Hz:
  ノッチが大きく旅して、ピークが笛のように唸る「深い渦」になるか。
  Feedback +97% まで上げても暴走せず、唸り止まりになるか
- Feedback をマイナス側に振ると、もうひとつの古典的な味になるか
- MIDI キーボードやコントローラーから CC 65 を送って
  ON/OFF が切り替わるか（ペダルやボタンの送信する値で試してください）
