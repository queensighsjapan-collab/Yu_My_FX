# YM Vortex かんたん手順（v1.1.0）

段数の多いフェイザーです。LFO が 2 本あるので、
うねりの模様が単純に繰り返さない、複雑な渦が作れます。
作り方は YM Echo / YM Orbit / YM Mirage と同じ要領です。

**v1.1.0 で変わったこと**：FEEDBACK が ±97% まで効くようになり
（前は ±85%）、DEPTH の上の方（66% より先）が深くうねるように
なりました。v1.0.0 で保存した設定はそのまま読めます。

## 1. ビルドする

フォルダーの中の **build.bat** をダブルクリックしてください。

- 黒い画面が出て、自動で進みます
- 初回だけ部品（JUCE）のダウンロードで数分かかります
- 最後に **DONE!** と出たら成功です

途中で [ERROR] が出て止まったら、同じフォルダーにできる
**build-log.txt** をマネージャーに送ってください。

## 2. プラグインを所定の場所に置く

ビルドが終わると、フォルダーの中に

```
build → YMVortex_artefacts → Release → VST3 → YM Vortex.vst3
```

という**フォルダー**ができています（ファイルじゃなくてフォルダーです）。

この **YM Vortex.vst3 フォルダーごと**、下の場所にコピーしてください。

```
C:\Program Files\Common Files\VST3
```

※ コピーのとき管理者権限の確認画面が出ます。「続行」でOKです。

## 3. DAW で試す

1. YM ORPHEUS（または Cakewalk Sonar）を起動
2. 初回は **Scan for Plugins...** を実行
3. トラックの FX に **YM Vortex** を挿す

## 4. 使い方の例

### ふつうのフェイザー

ギター、エレピ、パッドなどに：

- STAGES: **6**
- RATE: 0.3 Hz
- DEPTH: 70%
- FEEDBACK: 30%
- MIX: 50%

懐かしい、ゆっくりしたうねりになります。

### 複雑な渦（おすすめ）

- STAGES: **12**
- RATE: 0.2–0.5 Hz
- DEPTH: 80%
- RATIO: **1.62**
- DEPTH 2: **50%**
- FEEDBACK: 40–60%

LFO が 2 本、割り切れない速さで混ざるので、
うねりの模様が繰り返さず、ゆっくり変化し続けます。
WIDTH を 90° にすると左右のうねりもずれます。

### 深いうねり（v1.1 の新レシピ）

- STAGES: **12**
- DEPTH: **90–100%**
- FEEDBACK: **+80–95%**
- RATE: 0.1–0.3 Hz（ゆっくり）

ノッチが大きく動き回って、共振のピークが笛のように唸ります。
FEEDBACK は +97% まで上げても暴走しない作りにしてありますが、
音量は上がるので OUTPUT で少し下げると安心です。

### きつめのジェット感

- STAGES: 8–12
- FEEDBACK: 70% 前後
- CENTRE: 1200 Hz くらい
- RATE: 0.8 Hz

FEEDBACK をマイナスにすると、別の味の効き方になります。

## MIDI で ON/OFF する

YM Vortex は、MIDI の CC で効果の ON/OFF ができます
（今後の YM エフェクトの標準仕様です）。

- 初期設定は **CC 65**：値が 64 以上で ON、64 未満で OFF
- 変えたいときは画面下の **LEARN** を押してから、
  使いたいツマミやペダルを動かしてください
- LEARN を右クリックすると、CC 割り当てを消せます（OFF 表示）
- 画面下の **ON / OFF ボタン**でも切り替えられます

※ DAW 側で「エフェクトに MIDI を送る」設定が必要です。
Sonar ではエフェクトの MIDI 入力を有効にしてください。
（YM ORPHEUS では M3.3 以降、トラックの M→FX で送れます。）

## つまみの意味（英語表示のまま）

| 表示 | 意味 |
|---|---|
| RATE | うねりの速さ（LFO1） |
| DEPTH | うねりの深さ（LFO1） |
| RATIO | LFO2 の速さの倍率 |
| DEPTH 2 | LFO2 の混ぜ具合。0 で古典的な単独 LFO |
| CENTRE | うねりの中心音域 |
| FEEDBACK | 効きの強さと色。マイナスも可 |
| STAGES | 段数（4 / 6 / 8 / 12）。多いほどノッチが増える |
| WIDTH | 左右のうねりのずれ（度） |
| WAVE | LFO1 の波形（SINE / TRI） |
| MIX | 原音とエフェクトの混ぜ具合 |
| OUTPUT | 全体の音量 |
