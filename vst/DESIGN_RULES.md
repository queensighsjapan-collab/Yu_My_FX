# VST の設計ルール（Yu_My シリーズ共通）

不具合を繰り返さないための決まりごとです。新しいプラグインを作るとき、既存のものを直すときは、先にここを確認します。

## 1. 鳴らす・止める
- **内蔵シーケンサーとアルペジエーターは、RUN（または鍵盤を押している間）だけ鳴る。** DAW が再生中というだけで勝手に鳴らさない。
  - HOST SYNC は「どのクロックで動くか」を選ぶだけのスイッチ。オン／オフのスイッチにはしない。
  - RUN の初期値は OFF。
  - （経緯）YM303 0.2.0 と mini mogumogu 1.0.0 で、HOST SYNC ON のとき DAW 再生だけでシーケンサーが鳴り続ける不具合があった。
- RUN が OFF の間、MIDI 鍵盤は普通に弾ける。シーケンサー再生中だけ KEY>TRANS など別の役割にしてよい。
- 止めたとき（RUN OFF、DAW 停止、All Notes Off CC120/123、再生位置のジャンプ）に、音が残らない。ゲートのオフ待ち（保留）も必ず破棄する。
- シーケンサー側の状態（タイ、保留中のゲートオフ）は、開始時・停止時に必ずリセットする。

## 2. テスト（CI で毎回自動実行）
`.github/workflows/vst-tests.yml` が、push と PR のたびに全プラグインで次を実行する。失敗したらマージしない。
- スモークテスト（`tests/PluginSmoke.cpp`）：MIDI、シーケンサー／アルペジオ、DAW のクロック、状態の保存、全プリセット。
- **「鳴りっぱなし」ガード（必須）**：
  1. DAW 再生中でも RUN OFF（または鍵盤なし）なら無音。
  2. DAW 停止なら無音。
  3. RUN OFF／停止／All Notes Off のあと、一定時間で無音に戻る。
  4. 再生位置のジャンプや RUN の切り替えをランダムに行ったあとも、最後は無音に戻る（mini mogumogu の chaos テスト）。
- pluginval（strictness 5、エディターを開くテストを含む）。
- 新しいプラグインを作るときは、上の4項目を最初のスモークテストに入れてから機能を作る。

## 3. 配布（Actions）
- Mac は Universal（x86_64 + arm64）。`CMAKE_OSX_ARCHITECTURES` は **`project()` の前**に書く（後ろだと無視される）。ワークフローで `lipo -archs` を表示して確認する。
- Windows はインストーラー（.exe）、Mac は dmg（アドホック署名、公証なしの場合は xattr の案内を同梱）。
- リリースは workflow_dispatch の `release_tag` で下書き（draft）を作り、公開は人が行う。
