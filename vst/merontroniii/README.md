# MeronTronIII — テープリプレイ楽器 VST3 / スタンドアロン（v1.0.1）

2013年に SynthEdit で作られた VST2「MeronTronII」を、13年越しに復刻した
テープリプレイ（メロトロン系）楽器です。オリジナルの .sf2 とプロジェクトは
失われていたため、DLL 本体からサウンドフォントをサンプル単位で回収・復元
しました。ユーザーの方々から報告のあった **2つの死に音（Flute の A#3 /
Strings の D5）も修正済み** です（該当サンプルは隣接音からの移調で補完）。

Cakewalk Sonar、YM-Kithara など一般の VST3 ホストで使えます。
**単体版（Standalone）も同梱しています。**

## 音源について

- 5 テープセット：**Strings / Flute / Choir / Brass / Violin**（各35テープ、G2–F5）
- 元プラグインを無響に近い設定で全音レンダリングして復元したサンプルを使用
- Strings / Brass の一部は、原器自体がキーより低く鳴る癖があり、それも含めて当時の鳴り方を再現しています

## 使い方

| コントロール | 内容 |
|---|---|
| テープセットボタン | Strings / Flute / Choir / Brass / Violin の切り替え（MIDI プログラムチェンジ 0–4 でも切替可） |
| VOLUME | 全体音量 |
| TONE | ローパス。右で明るく、左でテープらしいこもった音に |
| ATTACK | 立ち上がりの速さ |
| RELEASE | 鍵を離したあとの余韻の長さ |
| HALF SPEED | テープを半分の速度で再生（1オクターブ下がって伸びやかに） |
| REVERB | 内蔵リバーブの量 |
| 画面キーボード | G2–F5 の35鍵。クリックでも、PCキーボード（A〜' のクロマチック）でも演奏可能 |

## ファイル配置（重要）

音源データ **MeronTronIII.sf2** が必須です。ビルドすると自動で
正しい場所にコピーされます。

- VST3版：`MeronTronIII.vst3` バンドル内 `Contents/Resources/` に入ります
  → バンドルフォルダごと `C:\Program Files\Common Files\VST3` へコピーしてください
- 単体版：`MeronTronIII.exe` と同じフォルダに置かれます
  → exe と sf2 は一緒に移動してください
