# MeronTronIII かんたん手順（v1.0.1）

2013年の MeronTronII を復刻したテープ楽器です。
死に音だった2音（Flute の A#3、Strings の D5）も直してあります。

## 1. ビルドする

フォルダーの中の **build.bat** をダブルクリックしてください。

- 黒い画面が出て、自動で進みます
- 初回だけ部品（JUCE）のダウンロードで数分かかります
- 最後に **DONE!** と出たら成功です

途中で [ERROR] が出て止まったら、同じフォルダーにできる
**build-log.txt** をマネージャーに送ってください。

## 2. 置き場所

### VST3 版（DAW で使う）

```
build → MeronTronIII_artefacts → Release → VST3 → MeronTronIII.vst3
```

この**フォルダーごと**、下の場所にコピーしてください。
（音源データはフォルダーの中に入っています。そのまま一緒にお願いします）

```
C:\Program Files\Common Files\VST3
```

### 単体版（DAW なしで使う）

```
build → MeronTronIII_artefacts → Release → Standalone → MeronTronIII.exe
```

**MeronTronIII.exe と、同じフォルダーにある MeronTronIII.sf2 を
一緒に好きな場所へ移して**、exe を実行するだけです。DAW は要りません。
初回は画面のオプション（歯車／Audio Settings）から
オーディオインターフェイスの入出力を選んでください。

## 3. DAW で試す（VST3 版）

1. YM-Kithara（または Cakewalk Sonar）を起動
2. 初回は **Scan for Plugins...** を実行
3. MIDI トラックの楽器に **MeronTronIII** を挿す

## 4. 使い方

### まず鳴らしてみる

- 画面下のキーボードをクリックすると鳴ります（単体版はこれで確認できます）
- PC のキーボードでも弾けます（A の列が G2 からのクロマチック配列）

### 音色（テープセット）

- 左下のボタンで **STRINGS / FLUTE / CHOIR / BRASS / VIOLIN** を切替
- MIDI のプログラムチェンジ 0〜4 でも切り替わります

### つまみ

- **VOLUME**：音量　**TONE**：音の明るさ
- **ATTACK**：立ち上がり　**RELEASE**：鍵を離した後の余韻
- **HALF SPEED**：テープ半速再生（1オクターブ下）
- **REVERB**：残響の量

鍵を押している間テープが回り、リールが回転します。
音が出ないときは、LCD に「NO TAPE LOADED」と出ていないか見てください
（MeronTronIII.sf2 が所定の場所にないと音源が読めません）。
